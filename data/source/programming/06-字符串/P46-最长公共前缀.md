# P46 最长公共前缀

- **标签**：#字符串
- **难度**：★☆☆☆☆
- **来源**：LeetCode 14

## 题目描述

给定 n 个仅由小写英文字母组成的非空字符串，求它们的最长公共前缀（Longest Common Prefix，LCP）。

若一个字符串 p 同时是这 n 个字符串的前缀，且不存在比它更长、同时也满足该性质的字符串，则称 p 为这 n 个字符串的最长公共前缀。若不存在任何非空的公共前缀，则最长公共前缀为空串。

## 输入格式

第一行一个整数 n（1 <= n <= 1000）。

接下来 n 行，每行一个非空字符串，仅由小写英文字母组成，不含空格。所有字符串的长度之和不超过 10^5。

本题只有一组测试数据。

## 输出格式

输出一行，表示这 n 个字符串的最长公共前缀。

特别地，若最长公共前缀为空串（即所有字符串没有公共的首字符），请输出一个空行（即仅输出一个换行符）。当 n = 1 时，答案就是该字符串本身。

## 样例输入

```text
3
flower
flow
flight
```

## 样例输出

```text
fl
```

## 数据范围

- 1 <= n <= 1000；
- 每个字符串非空，且仅由小写英文字母组成；
- 所有字符串的长度之和不超过 10^5；
- 只有一个测试文件、一组数据。

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

#define MAXL 100005

static char ans[MAXL], cur[MAXL];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    scanf("%s", ans);
    /* 以第一个串为初始前缀，逐个缩短 */
    int len = (int)strlen(ans);
    for (int i = 1; i < n; i++) {
        scanf("%s", cur);
        int j = 0;
        while (j < len && ans[j] == cur[j]) j++;
        len = j;
        ans[len] = '\0';
    }
    printf("%s\n", ans);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    string ans, cur;
    cin >> ans;
    // 以第一个串为初始前缀，逐个缩短
    for (int i = 1; i < n; ++i) {
        cin >> cur;
        size_t j = 0;
        while (j < ans.size() && j < cur.size() && ans[j] == cur[j]) ++j;
        ans.resize(j);
    }
    cout << ans << "\n";
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    ans = data[1].decode()
    # 以第一个串为初始前缀，逐个缩短
    for i in range(2, n + 1):
        cur = data[i].decode()
        j = 0
        limit = min(len(ans), len(cur))
        while j < limit and ans[j] == cur[j]:
            j += 1
        ans = ans[:j]
    sys.stdout.write(ans + "\n")


main()
```
