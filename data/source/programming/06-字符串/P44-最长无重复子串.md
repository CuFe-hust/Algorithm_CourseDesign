# P44 最长无重复子串

- **标签**：#字符串 #滑动窗口
- **难度**：★★★☆☆
- **来源**：LeetCode 3

## 题目描述

给定一个字符串 s，请求出其中不含重复字符的最长子串的长度。

子串是指 s 中一段连续字符组成的字符串。不含重复字符是指该子串中每个字符最多只出现一次。

## 输入格式

输入只有一行，一个字符串 s，长度满足 1 <= |s| <= 10^5。s 由可打印 ASCII 字符组成，不包含空格与换行。

## 输出格式

输出一行一个整数，表示最长不含重复字符的子串的长度。输出末尾换行。

## 样例输入

```text
abcabcbb
```

## 样例输出

```text
3
```

## 数据范围

- 1 <= |s| <= 10^5
- s 中的字符为 ASCII 码 33 到 126 的可见字符（含大小写字母、数字与标点符号），不包含空格与换行
- 子串必须是连续的一段字符
- 所有字符互不相同时答案即为 |s|；单个字符构成的子串一定不含重复字符，因此答案至少为 1

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

static char s[100005];
static int last[128];

int main(void) {
    if (scanf("%s", s) != 1) return 0;
    int n = (int)strlen(s);
    for (int i = 0; i < 128; i++) last[i] = -1;

    /* 滑动窗口：窗口内字符互不相同 */
    int left = 0, best = 0;
    for (int i = 0; i < n; i++) {
        int c = (unsigned char)s[i];
        if (last[c] >= left) left = last[c] + 1;
        last[c] = i;
        if (i - left + 1 > best) best = i - left + 1;
    }
    printf("%d\n", best);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    if (!(cin >> s)) return 0;
    vector<int> last(128, -1);

    // 滑动窗口：窗口内字符互不相同
    int left = 0, best = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        int c = (unsigned char)s[i];
        if (last[c] >= left) left = last[c] + 1;
        last[c] = i;
        best = max(best, i - left + 1);
    }
    cout << best << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    s = sys.stdin.buffer.readline().strip()
    if not s:
        return
    last = [-1] * 128
    left = 0
    best = 0
    # 滑动窗口：窗口内字符互不相同
    for i, c in enumerate(s):
        if last[c] >= left:
            left = last[c] + 1
        last[c] = i
        if i - left + 1 > best:
            best = i - left + 1
    sys.stdout.write(str(best) + "\n")


if __name__ == "__main__":
    main()
```
