# P45 子串哈希查询

- **标签**：#字符串 #哈希 #前缀和
- **难度**：★★★★☆
- **来源**：经典算法题（字符串哈希）

## 题目描述

给定一个长度为 n 的、仅由小写英文字母组成的字符串 s，字符串下标从 1 开始。共有 q 次询问，第 i 次询问给出四个整数 l_1, r_1, l_2, r_2，表示两个闭区间 [l_1, r_1] 与 [l_2, r_2]，分别对应子串 s[l_1..r_1] 与 s[l_2..r_2]。请判断这两个子串是否完全相同。

若两段子串长度不同，则它们一定不相同；长度相同时，当且仅当对应位置上的每个字符都相等，两段子串才相同。

## 输入格式

第一行一个字符串 s（1 <= |s| <= 10^5），仅包含小写英文字母，不含空格。

第二行一个整数 q（1 <= q <= 10^5）。

接下来 q 行，每行四个整数 l_1, r_1, l_2, r_2，满足 1 <= l_1 <= r_1 <= |s|，1 <= l_2 <= r_2 <= |s|。

本题只有一组测试数据。

## 输出格式

输出 q 行，每行一个字符串：若两个子串完全相同则输出 `Yes`，否则输出 `No`。大小写敏感，行末不要有多余空格。

## 样例输入

```text
abcabc
3
1 3 4 6
1 2 2 3
1 3 2 4
```

## 样例输出

```text
Yes
No
No
```

## 数据范围

- 1 <= |s| <= 10^5，字符串仅含小写英文字母；
- 1 <= q <= 10^5；
- 1 <= l_1 <= r_1 <= |s|，1 <= l_2 <= r_2 <= |s|；
- 所有区间均为闭区间，下标从 1 开始；
- 只有一个测试文件、一组数据。

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

#define MAXN 100005
#define MOD 1000000007
#define BASE 131

static char s[MAXN];
static unsigned long long h64[MAXN], pw64[MAXN];
static long long hmod[MAXN], pwmod[MAXN];

int main(void) {
    if (scanf("%s", s + 1) != 1) return 0;
    int n = (int)strlen(s + 1);
    h64[0] = 0; hmod[0] = 0;
    pw64[0] = 1; pwmod[0] = 1;
    /* 双哈希：64 位自然溢出 + 模 1e9+7 */
    for (int i = 1; i <= n; i++) {
        long long c = s[i] - 'a' + 1;
        pw64[i] = pw64[i - 1] * BASE;
        pwmod[i] = pwmod[i - 1] * BASE % MOD;
        h64[i] = h64[i - 1] * BASE + (unsigned long long)c;
        hmod[i] = (hmod[i - 1] * BASE + c) % MOD;
    }
    int q;
    if (scanf("%d", &q) != 1) return 0;
    while (q--) {
        int l1, r1, l2, r2;
        scanf("%d %d %d %d", &l1, &r1, &l2, &r2);
        if (r1 - l1 != r2 - l2) { puts("No"); continue; }
        int len = r1 - l1 + 1;
        unsigned long long a64 = h64[r1] - h64[l1 - 1] * pw64[len];
        unsigned long long b64 = h64[r2] - h64[l2 - 1] * pw64[len];
        long long am = (hmod[r1] - hmod[l1 - 1] * pwmod[len] % MOD + MOD) % MOD;
        long long bm = (hmod[r2] - hmod[l2 - 1] * pwmod[len] % MOD + MOD) % MOD;
        puts((a64 == b64 && am == bm) ? "Yes" : "No");
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    s = data[0].decode()
    n = len(s)
    MOD = 1000000007
    BASE = 131
    MASK = (1 << 64) - 1
    h64 = [0] * (n + 1)
    hmod = [0] * (n + 1)
    pw64 = [1] * (n + 1)
    pwmod = [1] * (n + 1)
    # 双哈希：64 位自然溢出 + 模 1e9+7
    for i in range(1, n + 1):
        c = ord(s[i - 1]) - 96
        pw64[i] = (pw64[i - 1] * BASE) & MASK
        pwmod[i] = pwmod[i - 1] * BASE % MOD
        h64[i] = (h64[i - 1] * BASE + c) & MASK
        hmod[i] = (hmod[i - 1] * BASE + c) % MOD
    q = int(data[1])
    out = []
    pos = 2
    for _ in range(q):
        l1 = int(data[pos]); r1 = int(data[pos + 1])
        l2 = int(data[pos + 2]); r2 = int(data[pos + 3])
        pos += 4
        if r1 - l1 != r2 - l2:
            out.append("No")
            continue
        length = r1 - l1 + 1
        a64 = (h64[r1] - h64[l1 - 1] * pw64[length]) & MASK
        b64 = (h64[r2] - h64[l2 - 1] * pw64[length]) & MASK
        am = (hmod[r1] - hmod[l1 - 1] * pwmod[length]) % MOD
        bm = (hmod[r2] - hmod[l2 - 1] * pwmod[length]) % MOD
        out.append("Yes" if a64 == b64 and am == bm else "No")
    sys.stdout.write("\n".join(out) + ("\n" if out else ""))


main()
```
