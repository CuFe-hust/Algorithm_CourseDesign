# P70 差分数组

- **标签**：#数组与模拟 #差分 #前缀和
- **难度**：★★★☆☆
- **来源**：经典算法题（差分数组）

## 题目描述

有一个长度为 n 的整数数组 a_1, a_2, ..., a_n，初始时所有元素均为 0。下标从 1 开始编号。

接下来依次执行 m 次操作。第 i 次操作给定三个整数 l_i, r_i, v_i，表示把下标在闭区间 [l_i, r_i] 内的所有元素都加上 v_i，即对每个满足 l_i<=j<=r_i 的下标 j 执行 a_j = a_j + v_i。

所有操作执行完毕后，请输出最终的数组。

## 输入格式

第一行包含两个整数 n 和 m（1<=n<=2*10^5，1<=m<=2*10^5），分别表示数组长度和操作次数。

接下来 m 行，每行包含三个整数 l_i, r_i, v_i（1<=l_i<=r_i<=n，|v_i|<=10^9），表示一次区间加法操作。

本题只有一组测试数据。

## 输出格式

输出一行，包含 n 个整数，依次为所有操作结束后的 a_1, a_2, ..., a_n。相邻两个整数之间用一个空格分隔，行末不得有多余空格。

## 样例输入

```text
5 2
1 3 2
2 4 1
```

## 样例输出

```text
2 3 3 1 0
```

## 数据范围

- 1<=n<=2*10^5
- 1<=m<=2*10^5
- 1<=l_i<=r_i<=n
- |v_i|<=10^9
- 本题只有一组测试数据
- 最终每个元素的绝对值可能达到 2*10^14，超出 32 位有符号整数的范围

## 标准实现

### C

```c
#include <stdio.h>

static long long d[200005];

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;

    // 区间 [l, r] 加 v：差分数组 d[l] += v, d[r+1] -= v
    for (int i = 0; i < m; i++) {
        int l, r;
        long long v;
        scanf("%d %d %lld", &l, &r, &v);
        d[l] += v;
        d[r + 1] -= v;
    }

    long long cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];
        if (i > 1) putchar(' ');
        printf("%lld", cur);
    }
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    vector<long long> d(n + 2, 0);
    for (int i = 0; i < m; i++) {
        int l, r;
        long long v;
        cin >> l >> r >> v;
        d[l] += v;
        d[r + 1] -= v;
    }

    long long cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];
        if (i > 1) cout << ' ';
        cout << cur;
    }
    cout << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, m = data[0], data[1]

    # 差分数组，下标从 1 到 n+1
    diff = [0] * (n + 2)
    p = 2
    for _ in range(m):
        l, r, v = data[p], data[p + 1], data[p + 2]
        p += 3
        diff[l] += v
        diff[r + 1] -= v

    cur = 0
    ans = []
    for i in range(1, n + 1):
        cur += diff[i]
        ans.append(str(cur))
    sys.stdout.write(' '.join(ans) + '\n')


if __name__ == '__main__':
    main()
```
