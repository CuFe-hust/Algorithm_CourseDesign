# P67 螺旋矩阵

- **标签**：#数组与模拟 #矩阵
- **难度**：★★☆☆☆
- **来源**：LeetCode 54

## 题目描述

给定一个 n 行 m 列的整数矩阵。请从左上角元素出发，按顺时针螺旋顺序输出矩阵中的所有元素。

具体顺序为：先沿着当前最外层的上边从左到右输出，再沿着右边从上到下输出，再沿着下边从右到左输出，再沿着左边从下到上输出；随后去掉这一层，对剩下的内层矩阵重复同样的过程，直到所有元素都被输出。若某一层只剩一行或一列，则按上述方向依次输出该行或该列中尚未输出的元素。

例如对于矩阵

1 2 3
4 5 6
7 8 9

按螺旋顺序得到的序列为 1 2 3 6 9 8 7 4 5。

## 输入格式

第一行包含两个整数 n 和 m（1<=n<=100，1<=m<=100），分别表示矩阵的行数和列数。

接下来 n 行，每行包含 m 个整数，其中第 i 行第 j 个整数表示矩阵第 i 行第 j 列的元素 a_{i,j}（|a_{i,j}|<=10^4）。

本题只有一组测试数据。

## 输出格式

输出一行，包含 n*m 个整数，为按螺旋顺序访问到的全部元素。相邻两个整数之间用一个空格分隔，行末不得有多余空格。

## 样例输入

```text
3 3
1 2 3
4 5 6
7 8 9
```

## 样例输出

```text
1 2 3 6 9 8 7 4 5
```

## 数据范围

- 1<=n<=100，1<=m<=100
- |a_{i,j}|<=10^4
- 本题只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

int a[105][105];

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            scanf("%d", &a[i][j]);

    int top = 0, bottom = n - 1, left = 0, right = m - 1;
    int first = 1;
    // 按上、右、下、左四条边依次取数并收缩边界
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) {
            if (!first) putchar(' ');
            printf("%d", a[top][j]);
            first = 0;
        }
        top++;
        for (int i = top; i <= bottom; i++) {
            if (!first) putchar(' ');
            printf("%d", a[i][right]);
            first = 0;
        }
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--) {
                if (!first) putchar(' ');
                printf("%d", a[bottom][j]);
                first = 0;
            }
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                if (!first) putchar(' ');
                printf("%d", a[i][left]);
                first = 0;
            }
            left++;
        }
    }
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;
    vector<vector<int>> a(n, vector<int>(m));
    for (auto &row : a)
        for (int &x : row)
            cin >> x;

    int top = 0, bottom = n - 1, left = 0, right = m - 1;
    vector<int> ans;
    ans.reserve(n * m);
    // 依次遍历当前层的上边、右边、下边、左边
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) ans.push_back(a[top][j]);
        top++;
        for (int i = top; i <= bottom; i++) ans.push_back(a[i][right]);
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--) ans.push_back(a[bottom][j]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) ans.push_back(a[i][left]);
            left++;
        }
    }

    for (int i = 0; i < (int)ans.size(); i++) {
        if (i > 0) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, m = data[0], data[1]
    a = [data[2 + i * m: 2 + (i + 1) * m] for i in range(n)]

    top, bottom, left, right = 0, n - 1, 0, m - 1
    ans = []
    # 顺时针逐层遍历，每层按上、右、下、左的顺序取数
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            ans.append(a[top][j])
        top += 1
        for i in range(top, bottom + 1):
            ans.append(a[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                ans.append(a[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                ans.append(a[i][left])
            left += 1

    sys.stdout.write(' '.join(map(str, ans)) + '\n')


if __name__ == '__main__':
    main()
```
