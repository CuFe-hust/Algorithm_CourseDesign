# P69 和为 k 的子数组个数

- **标签**：#数组与模拟 #前缀和 #哈希
- **难度**：★★★☆☆
- **来源**：LeetCode 560

## 题目描述

给定一个长度为 n 的整数数组 a_1, a_2, ..., a_n 和一个整数 k，请统计该数组中有多少个非空连续子数组的元素之和恰好等于 k。

连续子数组指原数组中下标连续的一段 a_l, a_{l+1}, ..., a_r，其中 1<=l<=r<=n。数组中的元素可能为正数、负数或零。两个子数组只要下标区间不同，就视为不同的子数组并分别计数。

## 输入格式

第一行包含两个整数 n 和 k（1<=n<=2*10^5，|k|<=10^9），分别表示数组长度和目标和的数值。

第二行包含 n 个整数 a_1, a_2, ..., a_n（|a_i|<=10^4），相邻两个整数之间用一个空格分隔。

本题只有一组测试数据。

## 输出格式

输出一行一个整数，表示元素之和恰好等于 k 的非空连续子数组的个数。

结果可能超过 32 位有符号整数能表示的范围。

## 样例输入

```text
5 2
1 1 1 -1 1
```

## 样例输出

```text
4
```

## 数据范围

- 1<=n<=2*10^5
- |k|<=10^9
- |a_i|<=10^4
- 本题只有一组测试数据
- 答案可能超过 32 位有符号整数的范围

## 标准实现

### C

```c
#include <stdio.h>

#define CAP (1 << 20)

static long long hkey[CAP];
static long long hcnt[CAP];
static unsigned char hused[CAP];

static unsigned long long mix(unsigned long long x) {
    x ^= x >> 33;
    x *= 0xff51afd7ed558ccdULL;
    x ^= x >> 33;
    x *= 0xc4ceb9fe1a85ec53ULL;
    x ^= x >> 33;
    return x;
}

// 开放寻址哈希表：找到键 k 对应的槽位，不存在则插入空槽
static int slot(long long k) {
    int h = (int)(mix((unsigned long long)k) & (CAP - 1));
    while (hused[h] && hkey[h] != k)
        h = (h + 1) & (CAP - 1);
    if (!hused[h]) {
        hused[h] = 1;
        hkey[h] = k;
        hcnt[h] = 0;
    }
    return h;
}

int main(void) {
    int n;
    long long k;
    if (scanf("%d %lld", &n, &k) != 2) return 0;

    int s = slot(0);
    hcnt[s] = 1;
    long long prefix = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        scanf("%lld", &x);
        prefix += x;
        s = slot(prefix - k);
        ans += hcnt[s];
        s = slot(prefix);
        hcnt[s]++;
    }
    printf("%lld\n", ans);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

// 自定义哈希函数，降低被固定哈希值影响而退化的可能
struct SplitMix {
    size_t operator()(long long x) const {
        unsigned long long z = (unsigned long long)x + 0x9e3779b97f4a7c15ULL;
        z = (z ^ (z >> 30)) * 0xbf58476d1ce4e5b9ULL;
        z = (z ^ (z >> 27)) * 0x94d049bb133111ebULL;
        return (size_t)(z ^ (z >> 31));
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long k;
    if (!(cin >> n >> k)) return 0;

    unordered_map<long long, long long, SplitMix> cnt;
    cnt.max_load_factor(0.7f);
    cnt.reserve(n + 10);
    cnt[0] = 1;

    long long prefix = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        prefix += x;
        auto it = cnt.find(prefix - k);
        if (it != cnt.end()) ans += it->second;
        cnt[prefix]++;
    }
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, k = data[0], data[1]
    nums = data[2:2 + n]

    # 前缀和与计数表，空前缀的初始计数为 1
    counts = {0: 1}
    prefix = 0
    ans = 0
    for x in nums:
        prefix += x
        ans += counts.get(prefix - k, 0)
        counts[prefix] = counts.get(prefix, 0) + 1
    sys.stdout.write(str(ans) + '\n')


if __name__ == '__main__':
    main()
```
