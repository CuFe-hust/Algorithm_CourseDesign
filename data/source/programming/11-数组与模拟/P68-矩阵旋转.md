# P68 矩阵旋转

- **标签**：#数组与模拟 #矩阵
- **难度**：★☆☆☆☆
- **来源**：经典算法题（矩阵旋转）

## 题目描述

给定一个 n 行 n 列的整数方阵，请将它顺时针旋转 90 度后输出。

旋转 90 度按下述对应关系理解：原矩阵中第 i 行第 j 列的元素，旋转后移动到新矩阵的第 j 行第 n-i+1 列（行、列均从 1 开始编号）。

## 输入格式

第一行包含一个整数 n（1<=n<=100），表示方阵的阶数。

接下来 n 行，每行包含 n 个整数，其中第 i 行第 j 个整数表示方阵第 i 行第 j 列的元素 a_{i,j}（|a_{i,j}|<=10^4）。

本题只有一组测试数据。

## 输出格式

输出 n 行，每行 n 个整数，表示顺时针旋转 90 度后的方阵。同一行内相邻两个整数之间用一个空格分隔，行末不得有多余空格。

## 样例输入

```text
2
1 2
3 4
```

## 样例输出

```text
3 1
4 2
```

## 数据范围

- 1<=n<=100
- |a_{i,j}|<=10^4
- 本题只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

int a[105][105];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            scanf("%d", &a[i][j]);

    // 顺时针旋转 90 度后，第 i 行来自原矩阵第 n-1-i 列
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) putchar(' ');
            printf("%d", a[n - 1 - j][i]);
        }
        putchar('\n');
    }
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<vector<int>> a(n, vector<int>(n));
    for (auto &row : a)
        for (int &x : row)
            cin >> x;

    // 旋转后位置 (i, j) 的元素是原矩阵的 (n-1-j, i)
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << ' ';
            cout << a[n - 1 - j][i];
        }
        cout << '\n';
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    a = [data[1 + i * n: 1 + (i + 1) * n] for i in range(n)]

    # 旋转后第 i 行第 j 列的元素是原矩阵的 a[n-1-j][i]
    out = []
    for i in range(n):
        out.append(' '.join(str(a[n - 1 - j][i]) for j in range(n)))
    sys.stdout.write('\n'.join(out) + '\n')


if __name__ == '__main__':
    main()
```
