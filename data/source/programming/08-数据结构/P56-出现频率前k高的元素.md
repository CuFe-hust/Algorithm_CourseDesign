# P56 出现频率前 k 高的元素

- **标签**：#数据结构 #堆 #哈希
- **难度**：★★★☆☆
- **来源**：LeetCode 347 变体

## 题目描述

给定 n 个整数和整数 k，请找出其中出现次数最多的 k 个不同的数，并按下列规则排序后输出：

1. 出现次数多的数排在前面；
2. 出现次数相同时，数值较小的数排在前面。

输入保证 k 不超过不同元素的个数。

## 输入格式

第一行两个整数 n 和 k，分别表示整数个数和需要输出的个数。

第二行包含 n 个整数 a_1, a_2, ..., a_n，相邻整数之间用一个空格分隔。

本题只有一组数据。

## 输出格式

输出一行，包含排序后的前 k 个数。相邻整数之间用一个空格分隔，行末不允许有多余空格。

## 样例输入

```text
6 2
1 1 1 2 2 3
```

## 样例输出

```text
1 2
```

## 数据范围

- 1 <= k <= m <= n <= 10^5，其中 m 为不同元素的个数
- |a_i| <= 10^9
- 所有整数均为 32 位有符号整数

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXN 100005

typedef struct {
    int val;
    int cnt;
} Node;

int a[MAXN];
Node b[MAXN];

int cmp_int(const void *x, const void *y) {
    int p = *(const int *)x;
    int q = *(const int *)y;
    return (p > q) - (p < q);
}

int cmp_node(const void *x, const void *y) {
    const Node *p = (const Node *)x;
    const Node *q = (const Node *)y;
    if (p->cnt != q->cnt) return (q->cnt > p->cnt) - (q->cnt < p->cnt);
    return (p->val > q->val) - (p->val < q->val);
}

int main(void) {
    int n, k;
    if (scanf("%d%d", &n, &k) != 2) return 0;
    for (int i = 0; i < n; ++i) scanf("%d", &a[i]);
    // 先按数值排序统计频次，再按次数降序、数值升序排列
    qsort(a, n, sizeof(int), cmp_int);
    int m = 0;
    for (int i = 0; i < n; ++i) {
        if (i == 0 || a[i] != a[i - 1]) {
            b[m].val = a[i];
            b[m].cnt = 1;
            ++m;
        } else {
            ++b[m - 1].cnt;
        }
    }
    qsort(b, m, sizeof(Node), cmp_node);
    for (int i = 0; i < k; ++i) {
        if (i) putchar(' ');
        printf("%d", b[i].val);
    }
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    unordered_map<long long, int> freq;
    freq.reserve(n * 2);
    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        ++freq[x];
    }
    vector<long long> vals;
    vals.reserve(freq.size());
    for (const auto &p : freq) vals.push_back(p.first);
    // 按出现次数降序排列，次数相同时按数值升序排列
    sort(vals.begin(), vals.end(), [&](long long x, long long y) {
        if (freq[x] != freq[y]) return freq[x] > freq[y];
        return x < y;
    });
    for (int i = 0; i < k; ++i) {
        if (i) cout << ' ';
        cout << vals[i];
    }
    cout << '\n';
    return 0;
}
```

### Python

```python
import sys
from collections import Counter


def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    k = int(data[1])
    cnt = Counter(map(int, data[2:2 + n]))
    # 按出现次数降序、数值升序排列，取前 k 个
    vals = sorted(cnt, key=lambda x: (-cnt[x], x))[:k]
    sys.stdout.write(" ".join(map(str, vals)) + "\n")


if __name__ == "__main__":
    main()
```
