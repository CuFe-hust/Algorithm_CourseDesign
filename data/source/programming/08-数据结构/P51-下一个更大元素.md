# P51 下一个更大元素

- **标签**：#数据结构 #单调栈
- **难度**：★★★☆☆
- **来源**：LeetCode 496/503 变体

## 题目描述

给定一个长度为 n 的整数数组 a_1, a_2, ..., a_n，下标从 1 开始。对于每个元素 a_i，请求出它右侧第一个严格大于它的元素，即找到最小的下标 j，满足 j > i 且 a_j > a_i。如果不存在这样的 j，则答案为 -1。

注意：相等的元素不算“大于”。例如数组 3 3 4 中，第一个 3 的答案是第二个 3 右侧的 4，而不是与它相等的第二个 3。

## 输入格式

输入只有一组测试数据。

第一行包含一个整数 n（1 <= n <= 10^5）。

第二行包含 n 个整数 a_1, a_2, ..., a_n（|a_i| <= 10^9），相邻整数之间用一个空格分隔。

## 输出格式

输出一行 n 个整数，第 i 个整数表示 a_i 的答案。相邻整数之间用一个空格分隔，行末不得有多余空格，输出末尾换行。若 a_i 右侧不存在严格大于它的元素，则输出 -1。

## 样例输入

```text
4
2 1 2 4
```

## 样例输出

```text
4 2 4 -1
```

## 数据范围

- 1 <= n <= 10^5
- |a_i| <= 10^9
- 输入只有一组测试数据
- 答案的取值在 32 位有符号整数范围内

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 100005

long long a[MAXN], st[MAXN], ans[MAXN];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++) {
        scanf("%lld", &a[i]);
    }

    // 从右向左维护单调递减栈，栈顶就是右侧第一个更大元素
    int top = 0;
    for (int i = n - 1; i >= 0; i--) {
        while (top > 0 && st[top - 1] <= a[i]) top--;
        ans[i] = (top > 0) ? st[top - 1] : -1;
        st[top++] = a[i];
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) putchar(' ');
        printf("%lld", ans[i]);
    }
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n), ans(n), st;
    st.reserve(n);
    for (long long &x : a) cin >> x;

    // 从右向左扫描，保持栈内元素单调递减
    for (int i = n - 1; i >= 0; --i) {
        while (!st.empty() && st.back() <= a[i]) st.pop_back();
        ans[i] = st.empty() ? -1 : st.back();
        st.push_back(a[i]);
    }

    for (int i = 0; i < n; ++i) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    a = data[1:1 + n]

    ans = [-1] * n
    stack = []
    # 从右向左维护单调递减栈
    for i in range(n - 1, -1, -1):
        while stack and stack[-1] <= a[i]:
            stack.pop()
        if stack:
            ans[i] = stack[-1]
        stack.append(a[i])

    sys.stdout.write(" ".join(map(str, ans)) + "\n")


if __name__ == "__main__":
    main()
```
