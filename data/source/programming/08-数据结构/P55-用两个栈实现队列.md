# P55 用两个栈实现队列

- **标签**：#数据结构 #栈 #队列
- **难度**：★★☆☆☆
- **来源**：经典算法题（用栈实现队列）

## 题目描述

本题要求使用两个栈模拟一个队列，队列初始为空。栈遵循后进先出原则，队列遵循先进先出原则。依次执行 q 条操作，操作共有三种：

- `push x`：将整数 x 放入队尾。
- `pop`：删除并输出当前队首元素；若队列为空，则输出 `empty`，且不删除任何元素。
- `front`：输出当前队首元素但不删除；若队列为空，则输出 `empty`。

所有操作按输入顺序依次执行。请给出每个 `pop` 或 `front` 操作的输出。

## 输入格式

第一行一个整数 q，表示操作条数。

接下来 q 行，每行一条操作，格式为 `push x`、`pop` 或 `front`，其中 x 为 32 位有符号整数。各字段之间用一个空格分隔。

本题只有一组数据。

## 输出格式

对于每个 `pop` 或 `front` 操作输出一行：若队列非空，输出对应的队首元素；若队列为空，输出字符串 `empty`。

## 样例输入

```text
7
push 1
push 2
front
pop
front
pop
pop
```

## 样例输出

```text
1
1
2
2
empty
```

## 数据范围

- 1 <= q <= 10^5
- 对于 `push` 操作，-2^{31} <= x <= 2^{31}-1
- 输入保证每条操作格式合法

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 100005

int in_stack[MAXN], out_stack[MAXN];
int in_top = 0, out_top = 0;

int main(void) {
    int q;
    scanf("%d", &q);
    char op[16];
    while (q--) {
        scanf("%15s", op);
        if (op[0] == 'p' && op[1] == 'u') {
            int x;
            scanf("%d", &x);
            in_stack[in_top++] = x;
        } else if (op[0] == 'p') {
            /* 出队或取队首前，把入栈中的元素依次转入出栈 */
            if (out_top == 0) {
                while (in_top > 0) out_stack[out_top++] = in_stack[--in_top];
            }
            if (out_top == 0) puts("empty");
            else printf("%d\n", out_stack[--out_top]);
        } else {
            if (out_top == 0) {
                while (in_top > 0) out_stack[out_top++] = in_stack[--in_top];
            }
            if (out_top == 0) puts("empty");
            else printf("%d\n", out_stack[out_top - 1]);
        }
    }
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    stack<int> in, out;
    while (q--) {
        string op;
        cin >> op;
        if (op == "push") {
            int x;
            cin >> x;
            in.push(x);
        } else {
            // 出队或取队首前，把入栈元素依次转移至出栈
            if (out.empty()) {
                while (!in.empty()) {
                    out.push(in.top());
                    in.pop();
                }
            }
            if (out.empty()) {
                cout << "empty\n";
            } else {
                cout << out.top() << '\n';
                if (op == "pop") out.pop();
            }
        }
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    q = int(data[0])
    in_stack = []
    out_stack = []
    pos = 1
    ans = []
    for _ in range(q):
        op = data[pos]
        pos += 1
        if op == b"push":
            in_stack.append(int(data[pos]))
            pos += 1
        elif op == b"pop":
            # 出队或取队首前，把入栈元素依次转移至出栈
            if not out_stack:
                while in_stack:
                    out_stack.append(in_stack.pop())
            ans.append(str(out_stack.pop()) if out_stack else "empty")
        else:
            if not out_stack:
                while in_stack:
                    out_stack.append(in_stack.pop())
            ans.append(str(out_stack[-1]) if out_stack else "empty")
    sys.stdout.write("\n".join(ans))
    if ans:
        sys.stdout.write("\n")


if __name__ == "__main__":
    main()
```
