# P53 后缀表达式求值

- **标签**：#数据结构 #栈
- **难度**：★★☆☆☆
- **来源**：经典算法题（逆波兰表达式）

## 题目描述

后缀表达式（逆波兰表达式）是把运算符写在参与运算的两个操作数之后的表达式。给定一个合法的后缀表达式，请计算它的值。

表达式中只包含非负整数操作数和二元运算符 +、-、*，不存在一元负号。求值时从左到右处理各个 token：遇到操作数时记下它的值；遇到运算符时，将它作用于此前最近得到且尚未参与运算的两个值，其中较先得到的是左操作数，较后得到的是右操作数，计算“左操作数 运算符 右操作数”并把结果作为新的值继续参与后续计算。表达式保证合法，因此每个运算符都有足够的操作数，最终恰好剩下一个值，这个值就是表达式的值。

例如，后缀表达式 `3 4 + 5 *` 的值为 (3 + 4) * 5 = 35。

## 输入格式

输入只有一行，包含若干个 token，token 之间用一个空格分隔，行末可能有换行。

- 操作数是非负整数，且 0 <= 操作数 <= 10^18。
- 运算符只可能是 `+`、`-`、`*`。
- 整行的字符数不超过 10^5。
- 保证表达式合法，且计算过程中的所有中间结果与最终结果均在 64 位有符号整数范围 [-2^63, 2^63 - 1] 内。

## 输出格式

输出一行一个整数，表示该后缀表达式的值。结果可能为负数，负数直接带负号输出；不得输出前导零（数字 0 本身除外）。输出末尾换行。

## 样例输入

```text
3 4 + 5 *
```

## 样例输出

```text
35
```

## 数据范围

- 整行字符数不超过 10^5
- 0 <= 操作数 <= 10^18
- 运算符只包含 +、-、*
- 中间结果和最终结果均在 64 位有符号整数范围内
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAXN 100005

long long st[MAXN];
char token[MAXN];

int main(void) {
    int top = 0;

    // 遇到操作数入栈，遇到运算符弹出两个操作数计算后入栈
    while (scanf("%s", token) == 1) {
        if (strcmp(token, "+") == 0 || strcmp(token, "-") == 0 ||
            strcmp(token, "*") == 0) {
            long long b = st[--top];
            long long a = st[--top];
            long long value;
            if (token[0] == '+') {
                value = a + b;
            } else if (token[0] == '-') {
                value = a - b;
            } else {
                value = a * b;
            }
            st[top++] = value;
        } else {
            st[top++] = strtoll(token, NULL, 10);
        }
    }

    printf("%lld\n", st[top - 1]);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    vector<long long> st;
    string token;
    // 按 token 类型分别执行入栈与二元运算
    while (cin >> token) {
        if (token == "+" || token == "-" || token == "*") {
            long long b = st.back();
            st.pop_back();
            long long a = st.back();
            st.pop_back();
            long long value;
            if (token == "+") {
                value = a + b;
            } else if (token == "-") {
                value = a - b;
            } else {
                value = a * b;
            }
            st.push_back(value);
        } else {
            st.push_back(stoll(token));
        }
    }

    cout << st.back() << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    tokens = sys.stdin.buffer.read().split()
    st = []
    # 读入全部 token，按后缀表达式的规则求值
    for token in tokens:
        if token == b"+" or token == b"-" or token == b"*":
            b = st.pop()
            a = st.pop()
            if token == b"+":
                st.append(a + b)
            elif token == b"-":
                st.append(a - b)
            else:
                st.append(a * b)
        else:
            st.append(int(token))

    sys.stdout.write(str(st[-1]) + "\n")


if __name__ == "__main__":
    main()
```
