# P54 树状数组

- **标签**：#数据结构 #树状数组 #前缀和
- **难度**：★★★★☆
- **来源**：经典算法题（Fenwick Tree）

## 题目描述

维护一个长度为 n 的整数数组 a_1, a_2, ..., a_n，下标从 1 开始，初始值由输入给出。需要支持 q 次操作，操作共有两种：

- `1 x v`：把 a_x 的值增加 v，即 a_x = a_x + v。v 可以为负数。
- `2 l r`：查询区间和 a_l + a_(l+1) + ... + a_r。

请按输入顺序处理所有操作，并对每次查询输出对应的区间和。

## 输入格式

输入只有一组测试数据。

第一行包含两个整数 n 和 q（1 <= n, q <= 2 * 10^5），分别表示数组长度和操作次数，两个整数之间用一个空格分隔。

第二行包含 n 个整数 a_1, a_2, ..., a_n（|a_i| <= 10^9），相邻整数之间用一个空格分隔。

接下来 q 行，每行表示一次操作，格式为以下两种之一：

- `1 x v`：把 a_x 增加 v（1 <= x <= n，|v| <= 10^9）。
- `2 l r`：查询从 a_l 到 a_r 的区间和（1 <= l <= r <= n）。

各整数之间用一个空格分隔。

## 输出格式

对于每个类型 2 的操作，输出一行一个整数，表示对应区间的元素之和。输出顺序与输入中查询操作的顺序一致，每行末尾换行。若输入中没有类型 2 的操作，则不输出任何内容。

## 样例输入

```text
5 4
1 2 3 4 5
2 1 5
1 3 10
2 3 3
2 1 3
```

## 样例输出

```text
15
13
16
```

## 数据范围

- 1 <= n, q <= 2 * 10^5
- |a_i| <= 10^9，|v| <= 10^9
- 1 <= l <= r <= n，1 <= x <= n
- 所有区间和的绝对值不超过 4 * 10^14，在 64 位有符号整数范围内
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 200005

long long bit[MAXN];
int n;

// 单点加与前缀和查询
void add(int i, long long v) {
    for (; i <= n; i += i & -i) {
        bit[i] += v;
    }
}

long long prefixSum(int i) {
    long long sum = 0;
    for (; i > 0; i -= i & -i) {
        sum += bit[i];
    }
    return sum;
}

int main(void) {
    int q;
    if (scanf("%d %d", &n, &q) != 2) return 0;

    for (int i = 1; i <= n; i++) {
        long long value;
        if (scanf("%lld", &value) != 1) return 0;
        add(i, value);
    }

    while (q--) {
        int op;
        if (scanf("%d", &op) != 1) return 0;
        if (op == 1) {
            int x;
            long long v;
            scanf("%d %lld", &x, &v);
            add(x, v);
        } else {
            int l, r;
            scanf("%d %d", &l, &r);
            printf("%lld\n", prefixSum(r) - prefixSum(l - 1));
        }
    }
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<long long> bit;

// 树状数组的下标更新与前缀和查询
void add(int i, long long v) {
    for (; i <= n; i += i & -i) {
        bit[i] += v;
    }
}

long long prefixSum(int i) {
    long long sum = 0;
    for (; i > 0; i -= i & -i) {
        sum += bit[i];
    }
    return sum;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    cin >> n >> q;
    bit.assign(n + 1, 0);

    for (int i = 1; i <= n; ++i) {
        long long value;
        cin >> value;
        add(i, value);
    }

    while (q--) {
        int op;
        cin >> op;
        if (op == 1) {
            int x;
            long long v;
            cin >> x >> v;
            add(x, v);
        } else {
            int l, r;
            cin >> l >> r;
            cout << prefixSum(r) - prefixSum(l - 1) << '\n';
        }
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, q = data[0], data[1]
    bit = [0] * (n + 1)
    pos = 2

    # 线性建树：先写入原值，再向父结点累加
    for i in range(1, n + 1):
        bit[i] += data[pos]
        pos += 1
        parent = i + (i & -i)
        if parent <= n:
            bit[parent] += bit[i]

    out = []
    for _ in range(q):
        op = data[pos]
        pos += 1
        if op == 1:
            x, v = data[pos], data[pos + 1]
            pos += 2
            while x <= n:
                bit[x] += v
                x += x & -x
        else:
            l, r = data[pos], data[pos + 1]
            pos += 2
            total = 0
            x = r
            while x > 0:
                total += bit[x]
                x -= x & -x
            x = l - 1
            while x > 0:
                total -= bit[x]
                x -= x & -x
            out.append(str(total))

    if out:
        sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    main()
```
