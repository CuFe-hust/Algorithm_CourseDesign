# P09 引爆气球

- **标签**：#贪心算法 #区间选点 #排序
- **难度**：★★★☆☆
- **来源**：LeetCode 452

## 题目描述

在一条水平直线上分布着 n 个气球。第 i 个气球占据闭区间 [x_i, y_i]，其中 x_i 与 y_i 都是整数，坐标轴上的位置 X 满足 x_i <= X <= y_i 时即认为该气球覆盖位置 X。

你可以从直线上的任意实数坐标 X 处竖直向上射出一支箭。这支箭会引爆所有覆盖位置 X 的气球（即满足 x_i <= X <= y_i 的全部气球），随后消失。一支箭只能射出一个坐标，但你可以射出任意多支箭，也允许在不同的箭中使用相同的坐标。

求引爆全部 n 个气球所需要的最少箭数。

## 输入格式

本题只有一组测试数据。

第一行一个整数 n。

接下来 n 行，第 i 行（1 <= i <= n）包含两个整数 x_i 与 y_i，表示第 i 个气球占据的闭区间 [x_i, y_i]，两个整数之间用一个空格分隔。

## 输出格式

输出一行一个整数，表示引爆全部气球所需的最少箭数。

## 样例输入

```text
4
10 16
2 8
1 6
7 12
```

## 样例输出

```text
2
```

## 数据范围

- 1 <= n <= 10^5
- 0 <= x_i <= y_i <= 10^9

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct { int x, y; } Seg;

int cmp(const void *a, const void *b) {
    const Seg *p = (const Seg *)a, *q = (const Seg *)b;
    if (p->y != q->y) return p->y < q->y ? -1 : 1;
    if (p->x != q->x) return p->x < q->x ? -1 : 1;
    return 0;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    Seg *s = (Seg *)malloc(sizeof(Seg) * (size_t)n);
    for (int i = 0; i < n; i++) scanf("%d %d", &s[i].x, &s[i].y);
    qsort(s, (size_t)n, sizeof(Seg), cmp);
    long long arrows = 0;
    int pos = -1;
    for (int i = 0; i < n; i++) {
        if (s[i].x > pos) { arrows++; pos = s[i].y; }
    }
    // 按右端点升序排序，每次在当前最左未覆盖气球的右端点射箭
    printf("%lld\n", arrows);
    free(s);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<pair<int, int>> seg(n);
    for (int i = 0; i < n; i++) cin >> seg[i].first >> seg[i].second;
    sort(seg.begin(), seg.end(), [](const pair<int, int> &a, const pair<int, int> &b) {
        if (a.second != b.second) return a.second < b.second;
        return a.first < b.first;
    });
    long long arrows = 0;
    int pos = -1;
    for (int i = 0; i < n; i++) {
        if (seg[i].first > pos) { arrows++; pos = seg[i].second; }
    }
    // 按右端点升序排序，每次在当前最左未覆盖气球的右端点射箭
    cout << arrows << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    seg = []
    idx = 1
    for _ in range(n):
        seg.append((data[idx], data[idx + 1]))
        idx += 2
    seg.sort(key=lambda p: (p[1], p[0]))
    arrows = 0
    pos = -1
    for x, y in seg:
        if x > pos:
            arrows += 1
            pos = y
    # 按右端点升序排序，每次在当前最左未覆盖气球的右端点射箭
    print(arrows)


main()
```
