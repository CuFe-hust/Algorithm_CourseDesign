# P04 合并果子

- **标签**：#贪心算法 #优先队列 #哈夫曼
- **难度**：★★★☆☆
- **来源**：NOIP 2004 提高组 / 洛谷 P1090

## 题目描述

在一个果园里，多多已经将所有的果子打了下来，并按果子的种类分成了 n 堆。第 i 堆果子的重量为 a_i。多多决定把所有果子合并成一堆。

每一次合并，多多可以任选两堆果子合并在一起，消耗的体力等于这两堆果子的重量之和。合并后，这两堆果子变成一堆，其重量等于原来的两堆重量之和。新形成的果子堆可以和剩余的果子堆继续合并。

请计算将所有果子合并成一堆所需要消耗的最小总体力。若一开始只有一堆果子，则不需要合并，总体力为 0。

## 输入格式

第一行一个整数 n，表示果子堆的数量。

第二行包含 n 个整数 a_1, a_2, ..., a_n，相邻两个整数用一个空格分隔，表示每一堆果子的重量。

## 输出格式

输出一行一个整数，表示将所有果子合并成一堆所需的最小总体力。

## 样例输入

```text
3
1 2 9
```

## 样例输出

```text
15
```

## 数据范围

- `1 ≤ n ≤ 10^4`
- `1 ≤ a_i ≤ 2 × 10^4`，其中 `1 ≤ i ≤ n`

## 标准实现

### C

```c
#include <stdio.h>

/* 小根堆：维护当前所有果子堆的重量 */
long long heap[10005];
int sz = 0;

void push(long long x) {
    int i = ++sz;
    while (i > 1 && heap[i / 2] > x) {
        heap[i] = heap[i / 2];
        i /= 2;
    }
    heap[i] = x;
}

long long pop(void) {
    long long ret = heap[1];
    long long x = heap[sz--];
    int i = 1;
    while (i * 2 <= sz) {
        int c = i * 2;
        if (c + 1 <= sz && heap[c + 1] < heap[c]) c++;
        if (heap[c] >= x) break;
        heap[i] = heap[c];
        i = c;
    }
    heap[i] = x;
    return ret;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; ++i) {
        long long x;
        scanf("%lld", &x);
        push(x);
    }

    /* 每次合并重量最小的两堆，代价累加 */
    long long ans = 0;
    while (sz > 1) {
        long long a = pop();
        long long b = pop();
        ans += a + b;
        push(a + b);
    }
    printf("%lld\n", ans);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    /* 小根堆：维护当前所有果子堆的重量 */
    priority_queue<long long, vector<long long>, greater<long long> > pq;
    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        pq.push(x);
    }

    /* 每次合并重量最小的两堆，代价累加 */
    long long ans = 0;
    while (pq.size() > 1) {
        long long a = pq.top();
        pq.pop();
        long long b = pq.top();
        pq.pop();
        ans += a + b;
        pq.push(a + b);
    }
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys
import heapq


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    heap = data[1:1 + n]
    heapq.heapify(heap)

    # 每次合并重量最小的两堆，代价累加
    ans = 0
    while len(heap) > 1:
        a = heapq.heappop(heap)
        b = heapq.heappop(heap)
        s = a + b
        ans += s
        heapq.heappush(heap, s)
    print(ans)


if __name__ == "__main__":
    main()
```
