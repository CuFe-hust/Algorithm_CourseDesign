# P08 跳跃游戏

- **标签**：#贪心算法 #数组
- **难度**：★★★☆☆
- **来源**：LeetCode 45

## 题目描述

给定一个长度为 n 的非负整数数组 a，元素下标从 0 开始。一开始你站在下标 0 处。

当站在下标 i 处时，你可以一步跳到任意满足 i < j <= i + a_i 的下标 j；若 a_i=0，则从下标 i 无法跳到任何位置。每一次这样的移动算作一次跳跃。

请计算从下标 0 跳到下标 n-1 所需要的最少跳跃次数。约定：

- 当 n=1 时，起点就是终点，最少跳跃次数为 0；
- 当无论如何都无法到达下标 n-1 时，输出 `-1`。

## 输入格式

本题只有一组测试数据。

第一行一个整数 n。

第二行 n 个非负整数 a_0, a_1, ..., a_{n-1}，相邻整数之间用一个空格分隔。

## 输出格式

输出一行一个整数，表示从下标 0 跳到下标 n-1 的最少跳跃次数；若无法到达，输出 `-1`。

## 样例输入

```text
5
2 3 1 1 4
```

## 样例输出

```text
2
```

## 数据范围

- 1 <= n <= 10^5
- 0 <= a_i <= 10^5

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    static int a[100005];
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    if (n == 1) { printf("0\n"); return 0; }
    long long jumps = 0;
    int cur_end = 0, farthest = 0, reachable = 1;
    for (int i = 0; i < n - 1; i++) {
        if (i + a[i] > farthest) farthest = i + a[i];
        if (i == cur_end) {
            if (farthest <= i) { reachable = 0; break; }
            jumps++;
            cur_end = farthest;
            if (cur_end >= n - 1) break;
        }
    }
    // 按层贪心：每层扩展当前能到达的最远位置
    if (reachable) printf("%lld\n", jumps);
    else printf("-1\n");
    return 0;
}
```

```cpp
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    if (n == 1) { cout << 0 << '\n'; return 0; }
    long long jumps = 0;
    int cur_end = 0, farthest = 0;
    bool reachable = true;
    for (int i = 0; i < n - 1; i++) {
        if (i + a[i] > farthest) farthest = i + a[i];
        if (i == cur_end) {
            if (farthest <= i) { reachable = false; break; }
            jumps++;
            cur_end = farthest;
            if (cur_end >= n - 1) break;
        }
    }
    // 按层贪心：每层扩展当前能到达的最远位置
    if (reachable) cout << jumps << '\n';
    else cout << -1 << '\n';
    return 0;
}
```

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))

    if n == 1:
        print(0)
        return
    jumps = 0
    cur_end = 0
    farthest = 0
    reachable = True
    for i in range(n - 1):
        if i + a[i] > farthest:
            farthest = i + a[i]
        if i == cur_end:
            if farthest <= i:
                reachable = False
                break
            jumps += 1
            cur_end = farthest
            if cur_end >= n - 1:
                break
    # 按层贪心：每层扩展当前能到达的最远位置
    print(jumps if reachable else -1)


main()
```
