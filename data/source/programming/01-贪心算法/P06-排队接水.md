# P06 排队接水

- **标签**：#贪心算法 #排序
- **难度**：★★☆☆☆
- **来源**：洛谷 P1223 / 经典贪心

## 题目描述

有 n 个人在同一个水龙头前排队接水。第 i 个人的原始编号为 i，他接水需要 t_i 分钟。

接水按队列顺序依次进行，只要有一个人接完水，下一个人就开始接水，水龙头不会空闲。第一个人开始接水的时刻记为 0。

一个人的等待时间定义为从时刻 0 开始到轮到他开始接水为止所经过的时间，不包括他自己接水所花的时间。也就是说，若他排在第 k 位（从 1 开始编号），他的等待时间等于排在他前面的 k - 1 个人的接水时间之和。

请确定接水顺序，使所有人的等待时间之和最小。

## 输入格式

第一行一个整数 n，表示人数。

第二行包含 n 个整数 t_1, t_2, ..., t_n，相邻两个整数用一个空格分隔，表示每个人接水所需的时间。

## 输出格式

输出两行。

第一行输出 n 个整数，表示接水顺序中每个人的原始编号。编号从 1 开始，相邻两个整数用一个空格分隔，行末不得有多余空格。顺序要求：按 t_i 从小到大排列；若 t_i 相同，则原始编号较小的排在前面。

第二行输出所有人的平均等待时间，即所有人等待时间之和除以 n，四舍五入保留恰好 2 位小数。

## 样例输入

```text
3
3 1 2
```

## 样例输出

```text
2 3 1
1.33
```

## 数据范围

- `1 ≤ n ≤ 1000`
- `1 ≤ t_i ≤ 10^6`，其中 `1 ≤ i ≤ n`

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int t;
    int id;
} Person;

int cmp(const void *a, const void *b) {
    const Person *x = (const Person *)a;
    const Person *y = (const Person *)b;
    if (x->t != y->t) return x->t < y->t ? -1 : 1;
    return x->id < y->id ? -1 : (x->id > y->id ? 1 : 0);
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    Person *a = (Person *)malloc(sizeof(Person) * n);
    for (int i = 0; i < n; ++i) {
        a[i].id = i + 1;
        scanf("%d", &a[i].t);
    }

    /* 接水时间升序，时间相同按原始编号升序 */
    qsort(a, n, sizeof(Person), cmp);

    long long total = 0, prefix = 0;
    for (int i = 0; i < n; ++i) {
        if (i > 0) printf(" ");
        printf("%d", a[i].id);
        total += prefix;
        prefix += a[i].t;
    }
    printf("\n");

    /* 平均等待时间乘以 100 后四舍五入 */
    long long cents = (total * 200 + n) / (2LL * n);
    printf("%lld.%02lld\n", cents / 100, cents % 100);
    free(a);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

struct Person {
    int t, id;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<Person> a(n);
    for (int i = 0; i < n; ++i) {
        a[i].id = i + 1;
        cin >> a[i].t;
    }

    /* 接水时间升序，时间相同按原始编号升序 */
    sort(a.begin(), a.end(), [](const Person &x, const Person &y) {
        if (x.t != y.t) return x.t < y.t;
        return x.id < y.id;
    });

    long long total = 0, prefix = 0;
    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << a[i].id;
        total += prefix;
        prefix += a[i].t;
    }
    cout << '\n';

    /* 平均等待时间乘以 100 后四舍五入 */
    long long cents = (total * 200 + n) / (2LL * n);
    cout << cents / 100 << '.';
    if (cents % 100 < 10) cout << '0';
    cout << cents % 100 << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    people = [(data[i + 1], i + 1) for i in range(n)]
    people.sort()  # 接水时间升序，时间相同按原始编号升序

    total = 0
    prefix = 0
    for t, _ in people:
        total += prefix
        prefix += t

    # 平均等待时间乘以 100 后四舍五入
    cents = (total * 200 + n) // (2 * n)
    print(" ".join(str(idx) for _, idx in people))
    print(f"{cents // 100}.{cents % 100:02d}")


if __name__ == "__main__":
    main()
```
