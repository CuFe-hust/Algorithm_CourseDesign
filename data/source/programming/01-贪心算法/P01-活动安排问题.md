# P01 活动安排问题

- **标签**：#贪心算法 #区间调度 #排序
- **难度**：★★☆☆☆
- **来源**：经典算法题（区间调度 / Activity Selection）

## 题目描述

有 n 个活动，第 i 个活动占用时间区间 [s_i, t_i]，其中 s_i 是开始时刻，t_i 是结束时刻。同一个人同一时刻只能参加一个活动。

如果前一个活动在时刻 t 结束，后一个活动在时刻 s 开始，且满足 t <= s，则这两个活动可以连续参加，也就是说，上一个活动结束的时刻可以恰好是下一个活动开始的时刻。活动可以按任意顺序选择，但参加的活动在时间上不能重叠（允许首尾相接）。

求这个人最多能参加多少个活动。

## 输入格式

第一行包含一个整数 n，表示活动的数量。

接下来 n 行，每行包含两个整数 s_i 和 t_i，用空格分隔，表示第 i 个活动的开始时刻和结束时刻。活动的给出顺序不保证按时间有序。

## 输出格式

输出一行，一个整数，表示最多能参加的活动数。

## 样例输入

```text
4
1 3
2 4
3 5
4 6
```

## 样例输出

```text
2
```

## 数据范围

- 1 <= n <= 1000
- 0 <= s_i < t_i <= 10^9
- 所有输入均为整数，没有多组数据。
- 允许 t_i = s_j，即一个活动结束的瞬间另一个活动可以开始。

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    long long s, t;
} Act;

int cmp(const void *a, const void *b) {
    const Act *x = (const Act *)a;
    const Act *y = (const Act *)b;
    if (x->t != y->t) return x->t < y->t ? -1 : 1;
    if (x->s != y->s) return x->s < y->s ? -1 : 1;
    return 0;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    Act *a = (Act *)malloc(sizeof(Act) * (size_t)n);
    if (a == NULL) return 0;
    for (int i = 0; i < n; ++i) {
        if (scanf("%lld %lld", &a[i].s, &a[i].t) != 2) {
            free(a);
            return 0;
        }
    }
    qsort(a, (size_t)n, sizeof(Act), cmp);
    int ans = 0;
    long long last = -1; /* 上一个选中活动的结束时刻 */
    for (int i = 0; i < n; ++i) {
        if (a[i].s >= last) {
            ++ans;
            last = a[i].t;
        }
    }
    printf("%d\n", ans);
    free(a);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<pair<long long, long long>> acts(n); // (结束时刻, 开始时刻)
    for (auto &act : acts) {
        long long s, t;
        cin >> s >> t;
        act = {t, s};
    }
    sort(acts.begin(), acts.end());

    int ans = 0;
    long long last = -1;
    for (const auto &act : acts) {
        if (act.second >= last) {
            ++ans;
            last = act.first;
        }
    }
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    acts = []
    pos = 1
    for _ in range(n):
        s = int(data[pos])
        t = int(data[pos + 1])
        pos += 2
        acts.append((t, s))  # (结束时刻, 开始时刻)
    acts.sort()

    ans = 0
    last = -1
    for t, s in acts:
        if s >= last:
            ans += 1
            last = t
    print(ans)

if __name__ == "__main__":
    main()
```
