# P05 区间覆盖

- **标签**：#贪心算法 #区间覆盖
- **难度**：★★★☆☆
- **来源**：经典算法题（最少区间覆盖）

## 题目描述

给定整数 m、n 以及 n 个闭区间 [l_i, r_i]。一个整数点 x 被区间 [l_i, r_i] 覆盖，当且仅当 l_i ≤ x ≤ r_i。

请从这些区间中选出最少数量的区间，使得从 1 到 m（包含 1 和 m）的每一个整数点都至少被一个选中的区间覆盖。每个输入区间至多选择一次。

判定覆盖时只看整数点，例如区间 [1, 2] 与 [3, 4] 恰好覆盖整数点 1、2、3、4。输入中的区间可以相交、相互包含或以任意顺序给出。

如果无法覆盖所有整数点，输出 -1；否则输出最少需要的区间数量。

## 输入格式

第一行包含两个整数 m 和 n，相邻两个整数用一个空格分隔。

接下来 n 行，每行包含两个整数 l_i 和 r_i，表示第 i 个闭区间。相邻两个整数用一个空格分隔。

## 输出格式

输出一行一个整数：最少需要的区间数量；若无法覆盖 1 到 m 的所有整数点，则输出 -1。

## 样例输入

```text
10 3
1 7
3 6
6 10
```

## 样例输出

```text
2
```

## 数据范围

- `1 ≤ m ≤ 10^9`
- `1 ≤ n ≤ 10^5`
- `1 ≤ l_i ≤ r_i ≤ m`，其中 `1 ≤ i ≤ n`

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    long long l, r;
} Seg;

int cmp(const void *a, const void *b) {
    const Seg *x = (const Seg *)a;
    const Seg *y = (const Seg *)b;
    if (x->l != y->l) return x->l < y->l ? -1 : 1;
    if (x->r != y->r) return x->r < y->r ? -1 : 1;
    return 0;
}

int main(void) {
    long long m;
    int n;
    if (scanf("%lld %d", &m, &n) != 2) return 0;
    Seg *a = (Seg *)malloc(sizeof(Seg) * n);
    for (int i = 0; i < n; ++i) {
        scanf("%lld %lld", &a[i].l, &a[i].r);
    }
    qsort(a, n, sizeof(Seg), cmp);

    /* 已覆盖 1..covered，每步选能接上且右端点最远的区间 */
    long long covered = 0;
    int idx = 0, ans = 0;
    while (covered < m) {
        long long best = covered;
        while (idx < n && a[idx].l <= covered + 1) {
            if (a[idx].r > best) best = a[idx].r;
            ++idx;
        }
        if (best == covered) {
            printf("-1\n");
            free(a);
            return 0;
        }
        covered = best;
        ++ans;
    }
    printf("%d\n", ans);
    free(a);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

struct Seg {
    long long l, r;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long m;
    int n;
    if (!(cin >> m >> n)) return 0;
    vector<Seg> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i].l >> a[i].r;
    }

    sort(a.begin(), a.end(), [](const Seg &x, const Seg &y) {
        if (x.l != y.l) return x.l < y.l;
        return x.r < y.r;
    });

    /* 已覆盖 1..covered，每步选能接上且右端点最远的区间 */
    long long covered = 0;
    int idx = 0, ans = 0;
    while (covered < m) {
        long long best = covered;
        while (idx < n && a[idx].l <= covered + 1) {
            best = max(best, a[idx].r);
            ++idx;
        }
        if (best == covered) {
            cout << -1 << '\n';
            return 0;
        }
        covered = best;
        ++ans;
    }
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    m, n = data[0], data[1]
    segs = []
    pos = 2
    for _ in range(n):
        segs.append((data[pos], data[pos + 1]))
        pos += 2
    segs.sort()

    # 已覆盖 1..covered，每步选能接上且右端点最远的区间
    covered = 0
    idx = 0
    ans = 0
    while covered < m:
        best = covered
        while idx < n and segs[idx][0] <= covered + 1:
            if segs[idx][1] > best:
                best = segs[idx][1]
            idx += 1
        if best == covered:
            print(-1)
            return
        covered = best
        ans += 1
    print(ans)


if __name__ == "__main__":
    main()
```
