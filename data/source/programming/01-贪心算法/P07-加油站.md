# P07 加油站

- **标签**：#贪心算法
- **难度**：★★★☆☆
- **来源**：LeetCode 134

## 题目描述

在一条环形公路旁有 n 个加油站，按顺时针方向依次编号为 0,1,...,n-1。第 i 个加油站储有 gas_i 升汽油；从第 i 个加油站出发，顺时针行驶到下一个加油站（i<n-1 时下一个是 i+1，i=n-1 时下一个是 0）需要消耗 cost_i 升汽油。

一辆汽车初始停在某个加油站，油箱为空，油箱容量无限大。出发时，汽车可以取走所停加油站的全部 gas_i 升汽油；此后每到达一个加油站（包括最后回到出发点），都可以取走该站的全部汽油。汽车只能在加油站取油，行驶途中没有其他油源。

请选择一个出发的加油站，使汽车沿顺时针方向依次经过全部 n 个加油站并最终回到出发点，且整个行驶过程中油箱里的油量始终不小于 0（即每一段路出发前，油箱中的油量必须不少于该段路消耗的 cost_i）。

输出这个出发加油站的编号（从 0 开始）。如果不存在这样的加油站，输出 `-1`。题目保证：若存在可行的出发加油站，则这样的加油站只有一个。

## 输入格式

本题只有一组测试数据。

第一行一个整数 n。

第二行 n 个整数 gas_0, gas_1, ..., gas_{n-1}，相邻整数之间用一个空格分隔。

第三行 n 个整数 cost_0, cost_1, ..., cost_{n-1}，相邻整数之间用一个空格分隔。

## 输出格式

输出一行一个整数，表示可行的出发加油站编号（从 0 开始）；若不存在，输出 `-1`。

## 样例输入

```text
5
1 2 3 4 5
3 4 5 1 2
```

## 样例输出

```text
3
```

## 数据范围

- 1 <= n <= 10^5
- 0 <= gas_i <= 10^4
- 0 <= cost_i <= 10^4
- 所有 gas_i 之和与所有 cost_i 之和均不超过 10^9

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    static int gas[100005], cost[100005];
    for (int i = 0; i < n; i++) scanf("%d", &gas[i]);
    for (int i = 0; i < n; i++) scanf("%d", &cost[i]);
    long long tank = 0, total = 0;
    int start = 0;
    for (int i = 0; i < n; i++) {
        long long d = (long long)gas[i] - cost[i];
        tank += d;
        total += d;
        if (tank < 0) { start = i + 1; tank = 0; }
    }
    // 总油量不足则无解，否则从第一个断点之后出发
    if (total < 0) printf("-1\n");
    else printf("%d\n", start % n);
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    gas = data[1:1 + n]
    cost = data[1 + n:1 + 2 * n]
    tank = 0
    total = 0
    start = 0
    for i in range(n):
        d = gas[i] - cost[i]
        tank += d
        total += d
        if tank < 0:
            start = i + 1
            tank = 0
    # 总油量不足则无解，否则从第一个断点之后出发
    print(-1 if total < 0 else start % n)


main()
```
