# P02 找零钱

- **标签**：#贪心算法 #货币系统
- **难度**：★★☆☆☆
- **来源**：经典算法题（最少货币张数）

## 题目描述

商店需要给顾客找零 N 元。可用的纸币面额为 1、2、5、10、20、50、100 元，每种面额的纸币数量不限。

请计算找零 N 元最少需要多少张纸币。要求所选纸币的面额之和恰好等于 N。当 N = 0 时不需要使用任何纸币，答案为 0。

## 输入格式

一行，一个整数 N。

## 输出格式

输出一行，一个整数，表示最少需要的纸币张数。

## 样例输入

```text
628
```

## 样例输出

```text
10
```

## 数据范围

- 0 <= N <= 10^9
- 输入只有一个整数，没有多组数据。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    long long n;
    if (scanf("%lld", &n) != 1) return 0;
    int face[7] = {100, 50, 20, 10, 5, 2, 1}; /* 面额从大到小 */
    long long ans = 0;
    for (int i = 0; i < 7; ++i) {
        ans += n / face[i];
        n %= face[i];
    }
    printf("%lld\n", ans);
    return 0;
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    if (!(cin >> n)) return 0;
    int face[7] = {100, 50, 20, 10, 5, 2, 1}; // 面额从大到小
    long long ans = 0;
    for (int x : face) {
        ans += n / x;
        n %= x;
    }
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    ans = 0
    for face in (100, 50, 20, 10, 5, 2, 1):
        ans += n // face
        n %= face
    print(ans)

if __name__ == "__main__":
    main()
```
