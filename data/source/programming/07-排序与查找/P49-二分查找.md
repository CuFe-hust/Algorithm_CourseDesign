# P49 二分查找

- **标签**：#查找 #二分查找
- **难度**：★☆☆☆☆
- **来源**：经典算法题（Binary Search）

## 题目描述

给定一个长度为 n 的非降序整数数组（即 a_1 ≤ a_2 ≤ … ≤ a_n）和 q 次询问。每次询问给出一个整数 x，请找出 x 在数组中第一次出现的位置。

数组下标从 1 开始。如果数组中不存在 x，则输出 -1。

## 输入格式

第一行包含两个整数 n 和 q，分别表示数组长度与询问次数，整数之间用一个空格分隔。

第二行包含 n 个整数 a_1, a_2, …, a_n，相邻两个整数之间用一个空格分隔，保证序列非降序。

接下来 q 行，每行一个整数 x，表示一次询问。

## 输出格式

输出 q 行，每行一个整数。若 x 在数组中存在，输出它第一次出现的下标（从 1 开始）；若不存在，输出 -1。

## 样例输入

```text
5 2
1 3 3 5 7
3
4
```

## 样例输出

```text
2
-1
```

## 数据范围

1 ≤ n, q ≤ 10^5，|a_i| ≤ 10^9，|x| ≤ 10^9。

## 标准实现

### C

```c
#include <stdio.h>

static int a[100005];

int main(void) {
    int n, q;
    scanf("%d %d", &n, &q);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    while (q--) {
        int x;
        scanf("%d", &x);
        int lo = 0, hi = n;          /* 找第一个大于等于 x 的位置 */
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        if (lo < n && a[lo] == x) printf("%d\n", lo + 1);
        else printf("-1\n");
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    n, q = data[0], data[1]
    a = data[2:2 + n]
    out = []
    pos = 2 + n
    for _ in range(q):
        x = data[pos]
        pos += 1
        lo, hi = 0, n                # 找第一个大于等于 x 的位置
        while lo < hi:
            mid = (lo + hi) // 2
            if a[mid] < x:
                lo = mid + 1
            else:
                hi = mid
        out.append(str(lo + 1) if lo < n and a[lo] == x else '-1')
    sys.stdout.write('\n'.join(out) + '\n')


main()
```
