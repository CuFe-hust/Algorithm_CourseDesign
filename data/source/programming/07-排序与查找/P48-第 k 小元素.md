# P48 第 k 小元素

- **标签**：#排序 #快速选择 #分治算法
- **难度**：★★★☆☆
- **来源**：经典算法题（Quickselect）

## 题目描述

给定 n 个整数，请找出其中第 k 小的数。相同的数值重复计数，例如序列 4 2 1 5 3 中第 3 小的数是 3，序列 2 2 5 中第 1 小和第 2 小的数都是 2。

数列下标从 1 开始，第 k 小指的是把序列按非降序排列后位于第 k 个位置的数。本题要求使用期望时间复杂度为 O(n) 的快速选择算法求解，请不要对整个序列进行完整排序。

## 输入格式

第一行包含两个整数 n 和 k，分别表示整数个数与要求的排名，整数之间用一个空格分隔。

第二行包含 n 个整数 a_1, a_2, …, a_n，相邻两个整数之间用一个空格分隔。

## 输出格式

输出一行一个整数，表示序列中第 k 小的数。

## 样例输入

```text
5 3
4 2 1 5 3
```

## 样例输出

```text
3
```

## 数据范围

1 ≤ k ≤ n ≤ 10^6，|a_i| ≤ 10^9。

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

static int a[1000005];

static void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

int main(void) {
    srand((unsigned)time(NULL));
    int n, k;
    scanf("%d %d", &n, &k);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    k--;                                /* 转成从 0 开始的下标 */
    int lo = 0, hi = n - 1;
    while (lo < hi) {
        int r = lo + rand() % (hi - lo + 1);
        swap(&a[r], &a[lo]);            /* 随机选取基准值 */
        int p = a[lo];
        int lt = lo, i = lo, gt = hi;
        while (i <= gt) {
            if (a[i] < p) swap(&a[lt++], &a[i++]);
            else if (a[i] > p) swap(&a[i], &a[gt--]);
            else i++;
        }
        if (k < lt) hi = lt - 1;
        else if (k > gt) lo = gt + 1;
        else { lo = lt; break; }        /* 基准值即为答案 */
    }
    printf("%d\n", a[lo]);
    return 0;
}
```

```cpp
        int r = lo + rand() % (hi - lo + 1);

        while (i <= gt) {
            if (a[i] < p) swap(a[lt++], a[i++]);

            else ++i;
```

### Python

```python
import sys
import random


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    n, k = data[0], data[1]
    a = data[2:2 + n]
    k -= 1                       # 转成从 0 开始的下标
    lo, hi = 0, n - 1
    while lo < hi:
        r = random.randrange(lo, hi + 1)
        a[r], a[lo] = a[lo], a[r]   # 随机选取基准值
        p = a[lo]
        lt, i, gt = lo, lo, hi
        while i <= gt:
            if a[i] < p:
                a[lt], a[i] = a[i], a[lt]
                lt += 1
                i += 1
            elif a[i] > p:
                a[i], a[gt] = a[gt], a[i]
                gt -= 1
            else:
                i += 1
        if k < lt:
            hi = lt - 1
        elif k > gt:
            lo = gt + 1
        else:
            lo = lt                  # 基准值即为答案
            break
    sys.stdout.write(str(a[lo]) + '\n')


main()
```
