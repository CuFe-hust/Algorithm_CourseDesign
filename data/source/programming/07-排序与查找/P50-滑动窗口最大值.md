# P50 滑动窗口最大值

- **标签**：#数据结构 #单调队列 #滑动窗口
- **难度**：★★★★☆
- **来源**：经典算法题 / 洛谷 P1886

## 题目描述

给定一个长度为 n 的整数序列 a_1, a_2, …, a_n 和一个正整数 k。

有一个大小为 k 的滑动窗口，最初覆盖序列中下标 1 到 k 的元素。此后每一步窗口向右移动一个位置，直到窗口覆盖下标 n-k+1 到 n 的元素为止。也就是说，窗口依次覆盖：

- 第 1 个窗口：a_1, a_2, …, a_k
- 第 2 个窗口：a_2, a_3, …, a_{k+1}
- ……
- 第 n-k+1 个窗口：a_{n-k+1}, a_{n-k+2}, …, a_n

请依次输出每个窗口内元素的最大值，共 n-k+1 个。

## 输入格式

第一行包含两个整数 n 和 k，分别表示序列长度与窗口大小，整数之间用一个空格分隔。

第二行包含 n 个整数 a_1, a_2, …, a_n，相邻两个整数之间用一个空格分隔。

## 输出格式

输出一行，包含 n-k+1 个整数，依次为每个窗口内元素的最大值，相邻两个整数之间用一个空格分隔。行末不得有多余空格。

## 样例输入

```text
8 3
1 3 -1 -3 5 3 6 7
```

## 样例输出

```text
3 3 5 5 6 7
```

## 数据范围

1 ≤ k ≤ n ≤ 10^6，|a_i| ≤ 10^9。

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 1000005
static int a[MAXN], dq[MAXN];   /* dq 存下标，对应值单调不增 */

int main(void) {
    int n, k;
    scanf("%d %d", &n, &k);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    int head = 0, tail = 0;
    for (int i = 0; i < n; i++) {
        while (head < tail && a[dq[tail - 1]] <= a[i]) tail--;
        dq[tail++] = i;
        if (dq[head] <= i - k) head++;      /* 队首已滑出窗口 */
        if (i >= k - 1) printf("%d%c", a[dq[head]], i == n - 1 ? '\n' : ' ');
    }
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <deque>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    deque<int> dq;                     // 存下标，对应值单调不增
    for (int i = 0; i < n; ++i) {
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();   // 队首已滑出窗口
        if (i >= k - 1) cout << a[dq.front()] << (i == n - 1 ? '\n' : ' ');
    }
    return 0;
}
```

### Python

```python
import sys
from collections import deque


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    n, k = data[0], data[1]
    a = data[2:2 + n]
    dq = deque()                 # 存下标，对应值单调不增
    out = []
    for i in range(n):
        while dq and a[dq[-1]] <= a[i]:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:       # 队首已滑出窗口
            dq.popleft()
        if i >= k - 1:
            out.append(str(a[dq[0]]))
    sys.stdout.write(' '.join(out) + '\n')


main()
```
