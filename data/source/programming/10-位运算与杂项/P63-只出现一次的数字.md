# P63 只出现一次的数字

- **标签**：#位运算 #异或
- **难度**：★★☆☆☆
- **来源**：LeetCode 136

## 题目描述

给定一个长度为奇数 n 的整数数组。数组中恰好有一个数只出现一次，其余每个数都恰好出现两次。请找出这个只出现一次的数。

要求算法的时间复杂度为 O(n)，额外空间复杂度为 O(1)。

## 输入格式

第一行一个整数 n，表示数组的长度。

第二行 n 个整数 a_1, a_2, ..., a_n，相邻两个整数之间用一个空格分隔。

## 输出格式

一行一个整数，表示只出现一次的那个数。行末需要换行。

## 样例输入

```text
5
4 1 2 1 2
```

## 样例输出

```text
4
```

## 数据范围

- 1 <= n <= 10^5，且 n 为奇数；
- |a_i| <= 10^9；
- 保证输入中恰好有一个数只出现一次，其余每个数都恰好出现两次。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    long long ans = 0, x;
    // 成对出现的数异或后相互抵消
    for (int i = 0; i < n; i++) {
        scanf("%lld", &x);
        ans ^= x;
    }
    printf("%lld\n", ans);
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    ans = 0
    # 成对出现的数异或后相互抵消
    for i in range(1, n + 1):
        ans ^= int(data[i])
    sys.stdout.write(str(ans) + "\n")


main()
```
