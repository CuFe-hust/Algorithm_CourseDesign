# P64 二进制中 1 的个数

- **标签**：#位运算 #lowbit
- **难度**：★☆☆☆☆
- **来源**：经典算法题（位运算 / Brian Kernighan）

## 题目描述

给定 T 个非负整数，请分别统计每个整数的二进制表示中数字 1 的个数。

例如，7 的二进制表示是 111，其中含有 3 个 1；0 的二进制表示中不含 1，答案为 0。

## 输入格式

第一行一个整数 T，表示数据的组数。

接下来 T 行，每行一个整数 x。

## 输出格式

共 T 行，第 i 行输出第 i 个整数的二进制表示中 1 的个数。每行一个整数，行末需要换行。

## 样例输入

```text
3
0
7
1024
```

## 样例输出

```text
0
3
1
```

## 数据范围

- 1 <= T <= 10^5；
- 0 <= x < 2^{60}。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int t;
    if (scanf("%d", &t) != 1) return 0;
    while (t--) {
        unsigned long long x;
        scanf("%llu", &x);
        int cnt = 0;
        // 每次消去最低位的 1
        while (x) {
            x &= x - 1;
            ++cnt;
        }
        printf("%d\n", cnt);
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    out = []
    # 统计二进制串中字符 1 的个数
    for i in range(1, t + 1):
        out.append(str(bin(int(data[i])).count("1")))
    sys.stdout.write("\n".join(out) + "\n")


main()
```
