# P66 数字范围按位与

- **标签**：#位运算
- **难度**：★★★☆☆
- **来源**：LeetCode 201

## 题目描述

给定两个整数 l 和 r（满足 0 ≤ l ≤ r），请计算闭区间 [l, r] 内所有整数（包含 l 和 r 本身）按位与（AND）的结果并输出。

按位与运算对两个整数的二进制表示逐位进行：只有当两个数在某一个二进制位上都为 1 时，结果的这一位才为 1，否则为 0。例如 5、6、7 的二进制表示分别是 101、110、111，它们按位与的结果是 100，即十进制 4。

本题只有一组测试数据。

## 输入格式

一行，两个整数 l 和 r，中间用一个空格分隔，满足 0 ≤ l ≤ r ≤ 2^31 − 1。

## 输出格式

一行，一个十进制整数，表示区间 [l, r] 内所有整数按位与的结果。输出不补前导零，行末不要有多余空格。

## 样例输入

```text
5 7
```

## 样例输出

```text
4
```

## 数据范围

- 0 ≤ l ≤ r ≤ 2^31 − 1，即 r 最大为 2147483647。
- 区间 [l, r] 至少包含一个整数；当 l = r 时，答案就是 l 本身。
- 答案一定落在 [0, 2^31 − 1] 内，不会出现负数。
- 本题只有一组测试数据，读入一次 l、r 后输出一行答案即可。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    long long l, r;
    if (scanf("%lld %lld", &l, &r) != 2) return 0;
    int shift = 0;
    // 不断右移，直到两端点相等，保留公共前缀
    while (l < r) {
        l >>= 1;
        r >>= 1;
        shift++;
    }
    printf("%lld\n", l << shift);
    return 0;
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long l, r;
    cin >> l >> r;
    int shift = 0;
    // 寻找 l 与 r 的公共二进制前缀
    while (l < r) {
        l >>= 1;
        r >>= 1;
        ++shift;
    }
    cout << (l << shift) << '\n';
    return 0;
}
```

import sys


def main():
    data = sys.stdin.buffer.read().split()
    if len(data) < 2:
        return
    l, r = int(data[0]), int(data[1])
    shift = 0
    # 不断右移直到 l 与 r 相等，公共前缀即为答案
    while l < r:
        l >>= 1
        r >>= 1
        shift += 1
    print(l << shift)


main()
