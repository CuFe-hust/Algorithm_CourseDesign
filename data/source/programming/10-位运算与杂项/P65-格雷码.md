# P65 格雷码

- **标签**：#位运算 #格雷码
- **难度**：★★☆☆☆
- **来源**：经典算法题（Gray Code）

## 题目描述

给定一个正整数 n，请输出 n 位格雷码序列。

第 i 个格雷码（i 从 0 开始编号）定义为

g(i) = i xor (i >> 1),

其中 xor 表示按位异或，>> 表示右移。请依次输出 i = 0, 1, ..., 2^n - 1 对应的 g(i)，每个格雷码用恰好 n 个字符的二进制串表示，不足 n 位时在高位（左侧）补 0。

## 输入格式

一行一个整数 n。

## 输出格式

共 2^n 行，每行一个长度为 n 的二进制串，只包含字符 `0` 和 `1`。第 i + 1 行（i 从 0 开始）为 g(i) 的 n 位二进制表示。每行行末需要换行。

## 样例输入

```text
2
```

## 样例输出

```text
00
01
11
10
```

## 数据范围

1 <= n <= 16。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    long long total = 1LL << n;
    char s[20];
    s[n] = '\0';
    // 第 i 个格雷码为 i ^ (i >> 1)
    for (long long i = 0; i < total; ++i) {
        unsigned int g = (unsigned int)(i ^ (i >> 1));
        for (int j = 0; j < n; ++j) {
            s[n - 1 - j] = (char)('0' + ((g >> j) & 1));
        }
        puts(s);
    }
    return 0;
}
```

```cpp
    // 第 i 个格雷码为 i ^ (i >> 1)
    for (long long i = 0; i < total; ++i) {
        unsigned int g = (unsigned int)(i ^ (i >> 1));

        cout << s << '\n';
    }
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    out = []
    # 第 i 个格雷码为 i ^ (i >> 1)，左侧补零到 n 位
    for i in range(1 << n):
        out.append(bin(i ^ (i >> 1))[2:].zfill(n))
    sys.stdout.write("\n".join(out) + "\n")


main()
```
