# P19 编辑距离

- **标签**：#动态规划 #字符串
- **难度**：★★★☆☆
- **来源**：LeetCode 72 / 经典算法题

## 题目描述

给定两个只由小写英文字母组成的字符串 s1 和 s2。

你可以对 s1 执行任意多次以下三种操作，每次操作的代价均为 1：

- 插入：在 s1 的任意位置（包括开头、结尾或两个字符之间）插入一个字符；
- 删除：删除 s1 中任意位置的一个字符；
- 替换：把 s1 中任意位置的一个字符替换成另一个字符。

求把 s1 变成 s2 所需的最小总代价，即两个字符串的编辑距离。两个字符串的长度可以不同。

## 输入格式

输入只有一组测试数据，共两行。

第一行是字符串 s1，第二行是字符串 s2。每个字符串都只由小写英文字母 a 到 z 组成，长度在 1 到 2000 之间（包含 1 和 2000）。字符串内部不含空格，行首和行尾也没有多余字符。

## 输出格式

输出一行一个整数，表示把 s1 变成 s2 的最少操作次数。若两个字符串已经相同，则输出 0。输出末尾换行。

## 样例输入

```text
horse
ros
```

## 样例输出

```text
3
```

## 数据范围

- 1 <= |s1|, |s2| <= 2000
- 字符串中只包含小写英文字母 a 到 z
- 答案是不超过 max(|s1|, |s2|) 的非负整数

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

static char s1[2005], s2[2005];
static int dp[2005];

int main(void) {
    if (scanf("%2004s", s1) != 1) return 0;
    if (scanf("%2004s", s2) != 1) return 0;
    int n = (int)strlen(s1);
    int m = (int)strlen(s2);
    for (int j = 0; j <= m; j++) dp[j] = j;
    for (int i = 1; i <= n; i++) {
        int diag = dp[0];
        dp[0] = i;
        for (int j = 1; j <= m; j++) {
            int up = dp[j];
            int cost = (s1[i - 1] == s2[j - 1]) ? 0 : 1;
            int best = up + 1;
            if (dp[j - 1] + 1 < best) best = dp[j - 1] + 1;
            if (diag + cost < best) best = diag + cost;
            dp[j] = best;
            diag = up;
        }
    }
    printf("%d\n", dp[m]);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s1, s2;
    if (!(cin >> s1)) return 0;
    if (!(cin >> s2)) return 0;

    int n = (int)s1.size();
    int m = (int)s2.size();
    vector<int> dp(m + 1);
    for (int j = 0; j <= m; ++j) dp[j] = j;

    for (int i = 1; i <= n; ++i) {
        int diag = dp[0];
        dp[0] = i;
        for (int j = 1; j <= m; ++j) {
            int up = dp[j];
            int cost = (s1[i - 1] == s2[j - 1]) ? 0 : 1;
            // 分别对应删除、插入、替换三种操作
            dp[j] = min({up + 1, dp[j - 1] + 1, diag + cost});
            diag = up;
        }
    }

    cout << dp[m] << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if len(data) < 2:
        return
    s1, s2 = data[0], data[1]
    m = len(s2)
    dp = list(range(m + 1))
    for i in range(1, len(s1) + 1):
        diag = dp[0]
        dp[0] = i
        ch = s1[i - 1]
        # 滚动数组：diag 保存替换操作所需的左上角值
        for j in range(1, m + 1):
            up = dp[j]
            cost = 0 if ch == s2[j - 1] else 1
            best = up + 1
            if dp[j - 1] + 1 < best:
                best = dp[j - 1] + 1
            if diag + cost < best:
                best = diag + cost
            dp[j] = best
            diag = up
    print(dp[m])


if __name__ == "__main__":
    main()
```
