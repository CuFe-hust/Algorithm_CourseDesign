# P24 最长公共子串

- **标签**：#动态规划 #字符串
- **难度**：★★★☆☆
- **来源**：经典算法题（Longest Common Substring）

## 题目描述

给定两个仅由小写英文字母组成的字符串 s 和 t，求它们的最长公共连续子串的长度。

「子串」是指原字符串中连续的一段字符。本题要求公共部分在 s 和 t 中都连续出现，注意与「最长公共子序列」区分：子序列只要求字符顺序相同，不要求字符连续。

两个字符串的长度可以不同。如果两个字符串不存在任何公共字符，则没有公共连续子串，此时答案为 0。

## 输入格式

输入共两行，每行一个仅由小写英文字母组成的字符串，第一行为 s，第二行为 t。

每个字符串的长度均不超过 5000，且至少为 1。输入只有一组测试数据，字符串中不含空格。

## 输出格式

输出一行一个整数，表示 s 与 t 的最长公共连续子串的长度。若不存在公共连续子串，输出 0。

## 样例输入

```text
abcdefg
cdefgh
```

## 样例输出

```text
5
```

## 数据范围

- 1 <= |s|, |t| <= 5000
- 字符串中只包含小写英文字母 a 到 z
- 单组测试数据

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

#define MAXN 5005

static char a[MAXN], b[MAXN];
static int pre[MAXN], cur[MAXN];

int main(void) {
    if (fgets(a, sizeof(a), stdin) == NULL) return 0;
    if (fgets(b, sizeof(b), stdin) == NULL) b[0] = '\0';
    a[strcspn(a, "\r\n")] = '\0';
    b[strcspn(b, "\r\n")] = '\0';
    int n = (int)strlen(a), m = (int)strlen(b), best = 0;
    /* cur[j] 表示以 a[i-1]、b[j-1] 结尾的最长公共子串长度 */
    for (int i = 1; i <= n; ++i) {
        cur[0] = 0;
        for (int j = 1; j <= m; ++j) {
            if (a[i - 1] == b[j - 1]) {
                cur[j] = pre[j - 1] + 1;
                if (cur[j] > best) best = cur[j];
            } else {
                cur[j] = 0;
            }
        }
        memcpy(pre, cur, sizeof(int) * (size_t)(m + 1));
    }
    /* 没有任何公共字符时答案为 0 */
    printf("%d\n", best);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string a, b;
    if (!getline(cin, a)) return 0;
    if (!getline(cin, b)) b.clear();
    if (!a.empty() && a.back() == '\r') a.pop_back();
    if (!b.empty() && b.back() == '\r') b.pop_back();
    int n = (int)a.size(), m = (int)b.size(), best = 0;
    // 滚动数组：pre 为上一行，cur 为当前行
    vector<int> pre(m + 1, 0), cur(m + 1, 0);
    for (int i = 1; i <= n; ++i) {
        cur[0] = 0;
        for (int j = 1; j <= m; ++j) {
            if (a[i - 1] == b[j - 1]) {
                cur[j] = pre[j - 1] + 1;
                best = max(best, cur[j]);
            } else {
                cur[j] = 0;
            }
        }
        swap(pre, cur);
    }
    cout << best << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if len(data) < 2:
        return
    s, t = data[0], data[1]
    # 对 s 建立后缀自动机，再让 t 在自动机上匹配
    nxt = [{}]
    link = [-1]
    length = [0]
    last = 0
    for c in s:
        cur = len(nxt)
        nxt.append({})
        length.append(length[last] + 1)
        link.append(0)
        p = last
        while p != -1 and c not in nxt[p]:
            nxt[p][c] = cur
            p = link[p]
        if p == -1:
            link[cur] = 0
        else:
            q = nxt[p][c]
            if length[p] + 1 == length[q]:
                link[cur] = q
            else:
                clone = len(nxt)
                nxt.append(nxt[q].copy())
                length.append(length[p] + 1)
                link.append(link[q])
                while p != -1 and nxt[p].get(c) == q:
                    nxt[p][c] = clone
                    p = link[p]
                link[q] = clone
                link[cur] = clone
        last = cur
    # 失配时沿后缀链接回退，l 为当前公共子串长度
    v = l = best = 0
    for c in t:
        while v and c not in nxt[v]:
            v = link[v]
            l = length[v]
        if c in nxt[v]:
            v = nxt[v][c]
            l += 1
        else:
            v = 0
            l = 0
        if l > best:
            best = l
    print(best)

main()
```
