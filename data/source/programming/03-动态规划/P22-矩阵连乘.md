# P22 矩阵连乘

- **标签**：#动态规划 #区间DP
- **难度**：★★★★☆
- **来源**：经典算法题（Matrix Chain Multiplication）

## 题目描述

给定 n 个矩阵 A_1, A_2, …, A_n，其中矩阵 A_i 的维度为 p_{i-1} 行、p_i 列（1 ≤ i ≤ n），即 A_i 是 p_{i-1} × p_i 的矩阵。

将这 n 个矩阵按顺序相乘：A_1 A_2 … A_n。矩阵乘法满足结合律，因此可以通过添加括号改变计算顺序，但矩阵的先后次序不能改变。

计算一个 x × y 的矩阵与一个 y × z 的矩阵相乘，需要 x × y × z 次标量乘法。请计算完成整个矩阵连乘所需的最少标量乘法次数。当 n = 1 时不需要做任何乘法，答案为 0。

## 输入格式

输入只有一组数据。

第一行一个整数 n。

第二行 n+1 个用空格分隔的整数 p_0, p_1, …, p_n。

## 输出格式

输出一行一个整数，表示最少的标量乘法次数。

答案可能超过 32 位有符号整数的范围，请使用 64 位整数保存。

## 样例输入

```text
3
10 100 5 50
```

## 样例输出

```text
7500
```

## 数据范围

- 1 ≤ n ≤ 100
- 1 ≤ p_i ≤ 10^4
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 100

long long dp[MAXN + 1][MAXN + 1];
int p[MAXN + 1];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i <= n; ++i) scanf("%d", &p[i]);
    // 区间 DP：枚举最后一次相乘的分割点
    for (int len = 2; len <= n; ++len) {
        for (int i = 1; i + len - 1 <= n; ++i) {
            int j = i + len - 1;
            dp[i][j] = -1;
            for (int k = i; k < j; ++k) {
                long long cur = dp[i][k] + dp[k + 1][j] + (long long)p[i - 1] * p[k] * p[j];
                if (dp[i][j] == -1 || cur < dp[i][j]) dp[i][j] = cur;
            }
        }
    }
    printf("%lld\n", dp[1][n]);
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    p = data[1:1 + n + 1]
    dp = [[0] * (n + 1) for _ in range(n + 1)]
    # 区间 DP：枚举最后一次相乘的分割点
    for length in range(2, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            best = 10 ** 30
            for k in range(i, j):
                cur = dp[i][k] + dp[k + 1][j] + p[i - 1] * p[k] * p[j]
                if cur < best:
                    best = cur
            dp[i][j] = best
    print(dp[1][n])


main()
```
