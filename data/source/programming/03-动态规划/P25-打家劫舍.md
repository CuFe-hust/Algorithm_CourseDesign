# P25 打家劫舍

- **标签**：#动态规划
- **难度**：★★☆☆☆
- **来源**：LeetCode 198

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房屋内都藏有若干现金（可能为 0），而相邻的房屋装有相互连通的防盗系统：如果两间相邻的房屋在同一晚被闯入，系统会自动报警。

现在有 n 间房屋沿街排成一排，第 i 间房屋内放有 a_i 元钱（1 <= i <= n）。小偷不能同时偷窃相邻的两间房屋，求在不触动报警系统的前提下，一夜之内能够偷到的最大金额。

小偷可以选择一间房屋也不偷，此时偷到的金额为 0。

## 输入格式

第一行一个整数 n（1 <= n <= 10^5），表示房屋的数量。

第二行 n 个用空格分隔的整数 a_1, a_2, ..., a_n（0 <= a_i <= 10^4），依次表示每间房屋内的现金数额。

输入只有一组测试数据。

## 输出格式

输出一行一个整数，表示小偷一夜之内能够偷到的最大金额。

## 样例输入

```text
4
2 7 9 3
```

## 样例输出

```text
11
```

## 数据范围

- 1 <= n <= 10^5
- 0 <= a_i <= 10^4
- 单组测试数据
- 答案不超过 10^9，可安全地用 64 位整数保存

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    long long prev2 = 0, prev1 = 0;
    /* prev2 表示 dp[i-2]，prev1 表示 dp[i-1]，读一个数滚动一次 */
    for (int i = 0; i < n; ++i) {
        long long x;
        if (scanf("%lld", &x) != 1) break;
        long long cur = prev1 > prev2 + x ? prev1 : prev2 + x;
        prev2 = prev1;
        prev1 = cur;
    }
    printf("%lld\n", prev1);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    // dp[i] = max(dp[i-1], dp[i-2] + a[i])，用两个变量滚动
    long long prev2 = 0, prev1 = 0;
    for (int i = 0; i < n; ++i) {
        long long cur = max(prev1, prev2 + a[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    cout << prev1 << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    a = data[1:1 + n]
    prev2 = prev1 = 0
    # 只保留前两户的最优值，逐个房屋转移
    for x in a:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    print(prev1)

main()
```
