# P20 数字三角形

- **标签**：#动态规划
- **难度**：★★☆☆☆
- **来源**：洛谷 P1216 / IOI 1994

## 题目描述

给定一个 n 行的数字三角形。第 i 行包含 i 个整数，其中第 i 行第 j 个整数记为 a_{i,j}（1 ≤ i ≤ n，1 ≤ j ≤ i）。

从三角形顶部，也就是第 1 行第 1 个数字出发，每一步可以走到下一行相邻的两个位置之一：如果当前位于第 i 行第 j 个位置，那么下一步可以走到第 i+1 行第 j 个位置，或者走到第 i+1 行第 j+1 个位置。

一直走到第 n 行时停止。路径上经过的所有数字（包括起点和终点）之和称为这条路径的路径和。请计算所有从顶部走到底部的合法路径中，最大的路径和。

## 输入格式

输入只有一组数据。

第一行一个整数 n。

接下来 n 行，第 i 行包含 i 个用空格分隔的整数，依次表示 a_{i,1}, a_{i,2}, …, a_{i,i}。

## 输出格式

输出一行一个整数，表示最大路径和。

## 样例输入

```text
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

## 样例输出

```text
30
```

## 数据范围

- 1 ≤ n ≤ 1000
- -10^4 ≤ a_{i,j} ≤ 10^4
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 1000

int dp[MAXN + 1][MAXN + 1];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= i; ++j)
            scanf("%d", &dp[i][j]);
    // 自底向上递推，每个位置选两个子结点中的较大值
    for (int i = n - 1; i >= 1; --i)
        for (int j = 1; j <= i; ++j) {
            int best = dp[i + 1][j] > dp[i + 1][j + 1] ? dp[i + 1][j] : dp[i + 1][j + 1];
            dp[i][j] += best;
        }
    printf("%d\n", dp[1][1]);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    if (!(std::cin >> n)) return 0;
    std::vector<std::vector<int>> dp(n + 1, std::vector<int>(n + 2, 0));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= i; ++j)
            std::cin >> dp[i][j];
    // 自底向上递推，每个位置选两个子结点中的较大值
    for (int i = n - 1; i >= 1; --i)
        for (int j = 1; j <= i; ++j)
            dp[i][j] += std::max(dp[i + 1][j], dp[i + 1][j + 1]);
    std::cout << dp[1][1] << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    # 按行还原三角形，再自底向上合并
    dp = []
    idx = 1
    for i in range(1, n + 1):
        dp.append(data[idx:idx + i])
        idx += i
    for i in range(n - 2, -1, -1):
        for j in range(i + 1):
            dp[i][j] += max(dp[i + 1][j], dp[i + 1][j + 1])
    print(dp[0][0])


main()
```
