# P17 最长公共子序列

- **标签**：#动态规划 #字符串
- **难度**：★★★☆☆
- **来源**：经典算法题（LCS）

## 题目描述

给定两个只由小写英文字母组成的字符串 s1 和 s2。

字符串的子序列是指从原字符串中删除零个或多个字符后，不改变剩余字符的相对顺序而得到的字符串；被删除的字符在原字符串中不要求相邻。例如，对于字符串 abcde，ace、abcde 和空串都是它的子序列，而 aec 不是。

如果字符串 t 同时是 s1 和 s2 的子序列，则称 t 是 s1 和 s2 的公共子序列。求 s1 和 s2 的最长公共子序列的长度。空串也是公共子序列，因此答案一定存在；当两个字符串没有公共字符时，答案为 0。

## 输入格式

输入只有一组测试数据，共两行。

第一行是字符串 s1，第二行是字符串 s2。每个字符串都只由小写英文字母 a 到 z 组成，长度在 1 到 1000 之间（包含 1 和 1000）。字符串内部不含空格，行首和行尾也没有多余字符。

## 输出格式

输出一行一个整数，表示 s1 和 s2 的最长公共子序列的长度。输出末尾换行。

## 样例输入

```text
abcde
ace
```

## 样例输出

```text
3
```

## 数据范围

- 1 <= |s1|, |s2| <= 1000
- 字符串中只包含小写英文字母 a 到 z
- 答案是不超过 min(|s1|, |s2|) 的非负整数

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

static char s1[1005], s2[1005];
static int dp[1005];

int main(void) {
    if (scanf("%1004s", s1) != 1) return 0;
    if (scanf("%1004s", s2) != 1) return 0;
    int n = (int)strlen(s1);
    int m = (int)strlen(s2);
    for (int i = 1; i <= n; i++) {
        int diag = 0; /* 滚动数组中保存左上角 dp[i-1][j-1] */
        for (int j = 1; j <= m; j++) {
            int up = dp[j];
            if (s1[i - 1] == s2[j - 1])
                dp[j] = diag + 1;
            else if (dp[j - 1] > dp[j])
                dp[j] = dp[j - 1];
            diag = up;
        }
    }
    printf("%d\n", dp[m]);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s1, s2;
    if (!(cin >> s1)) return 0;
    if (!(cin >> s2)) return 0;

    int n = (int)s1.size();
    int m = (int)s2.size();
    vector<int> dp(m + 1, 0);
    for (int i = 1; i <= n; ++i) {
        int diag = 0;
        for (int j = 1; j <= m; ++j) {
            int up = dp[j];
            if (s1[i - 1] == s2[j - 1])
                dp[j] = diag + 1;
            else
                dp[j] = max(dp[j], dp[j - 1]);
            diag = up;
        }
    }

    cout << dp[m] << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if len(data) < 2:
        return
    s1, s2 = data[0], data[1]
    m = len(s2)
    dp = [0] * (m + 1)
    for i in range(1, len(s1) + 1):
        diag = 0
        ch = s1[i - 1]
        # 滚动数组中的 diag 保存左上角的值
        for j in range(1, m + 1):
            up = dp[j]
            if ch == s2[j - 1]:
                dp[j] = diag + 1
            elif dp[j - 1] > dp[j]:
                dp[j] = dp[j - 1]
            diag = up
    print(dp[m])


if __name__ == "__main__":
    main()
```
