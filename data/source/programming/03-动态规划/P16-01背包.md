# P16 01背包

- **标签**：#动态规划 #背包问题
- **难度**：★★★☆☆
- **来源**：经典算法题（0/1 Knapsack）

## 题目描述

有 n 件物品和一个容量为 W 的背包。第 i 件物品的重量为 w_i，价值为 v_i。每件物品只有一件，最多只能被选择一次；物品不可分割，只能整件放入背包。

请从这 n 件物品中选出若干件放入背包，使得放入背包的物品总重量不超过 W，并且总价值尽可能大。求这个最大总价值。如果没有任何物品能够放入背包，最大总价值为 0。

## 输入格式

输入只有一组测试数据。

第一行包含两个整数 n 和 W（1 <= n <= 1000，1 <= W <= 1000），分别表示物品数量和背包容量，两个整数之间用一个空格分隔。

接下来 n 行，第 i 行包含两个整数 w_i 和 v_i（1 <= w_i <= 1000，0 <= v_i <= 10^4），分别表示第 i 件物品的重量和价值，两个整数之间用一个空格分隔。物品按输入顺序从 1 开始编号。

## 输出格式

输出一行一个整数，表示在总重量不超过 W 的前提下能够获得的最大总价值。输出末尾换行。

## 样例输入

```text
4 5
1 2
2 4
3 4
4 5
```

## 样例输出

```text
8
```

## 数据范围

- 1 <= n <= 1000
- 1 <= W <= 1000
- 1 <= w_i <= 1000
- 0 <= v_i <= 10^4
- 单件物品的重量可能大于背包容量 W，此时该物品无法被选中。
- 最大总价值不超过 10^7。

## 标准实现

### C

```c
#include <stdio.h>

int dp[1005];

int main(void) {
    int n, W;
    if (scanf("%d %d", &n, &W) != 2) return 0;
    for (int i = 0; i < n; i++) {
        int w, v;
        if (scanf("%d %d", &w, &v) != 2) return 0;
        /* 逆序枚举容量，保证每件物品至多被选一次 */
        for (int j = W; j >= w; j--) {
            int cand = dp[j - w] + v;
            if (cand > dp[j]) dp[j] = cand;
        }
    }
    printf("%d\n", dp[W]);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, W;
    if (!(cin >> n >> W)) return 0;

    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; ++i) {
        int w, v;
        cin >> w >> v;
        // 逆序遍历容量，避免同一件物品被重复选择
        for (int j = W; j >= w; --j) {
            dp[j] = max(dp[j], dp[j - w] + v);
        }
    }

    cout << dp[W] << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, W = data[0], data[1]
    dp = [0] * (W + 1)
    idx = 2
    for _ in range(n):
        w, v = data[idx], data[idx + 1]
        idx += 2
        # 逆序更新容量，保证每件物品最多被选一次
        for j in range(W, w - 1, -1):
            cand = dp[j - w] + v
            if cand > dp[j]:
                dp[j] = cand
    print(dp[W])


if __name__ == "__main__":
    main()
```
