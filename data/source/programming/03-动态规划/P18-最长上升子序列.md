# P18 最长上升子序列

- **标签**：#动态规划 #二分
- **难度**：★★★☆☆
- **来源**：经典算法题（LIS）

## 题目描述

给定一个长度为 n 的整数序列 a_1, a_2, ..., a_n。

序列的子序列是指从原序列中删除零个或多个元素后，保持剩余元素的相对顺序不变而得到的序列。例如，对于序列 [3, 1, 4, 1, 5]，[3, 4, 5] 和 [1, 1] 都是它的子序列。

如果子序列 b_1, b_2, ..., b_k 满足 b_1 < b_2 < ... < b_k，则称它是严格上升子序列。注意相邻两项必须严格小于，相等的两个元素不能同时出现在严格上升子序列中。求给定序列的最长严格上升子序列的长度。

## 输入格式

输入只有一组测试数据，共两行。

第一行是一个整数 n（1 <= n <= 10^5），表示序列的长度。

第二行包含 n 个整数 a_1, a_2, ..., a_n（|a_i| <= 10^9），相邻两个整数之间用一个空格分隔。

## 输出格式

输出一行一个整数，表示最长严格上升子序列的长度。输出末尾换行。

## 样例输入

```text
8
10 9 2 5 3 7 101 18
```

## 样例输出

```text
4
```

## 数据范围

- 1 <= n <= 10^5
- |a_i| <= 10^9
- 序列中的元素可以相同，也可以为负数或零
- 答案不超过 n

## 标准实现

### C

```c
#include <stdio.h>

static long long tails[100005];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    int len = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        if (scanf("%lld", &x) != 1) return 0;
        /* 找到第一个不小于 x 的位置并替换，保持严格上升 */
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;
        if (lo == len) len++;
    }
    printf("%d\n", len);
    return 0;
}
```

### C++

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<long long> tails;
    tails.reserve(n);
    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        // 严格上升：用 lower_bound 找第一个大于等于 x 的位置
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end())
            tails.push_back(x);
        else
            *it = x;
    }

    cout << (int)tails.size() << '\n';
    return 0;
}
```

### Python

```python
import sys
from bisect import bisect_left


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    tails = []
    # 严格上升：用 bisect_left 找第一个大于等于当前值的位置
    for i in range(1, n + 1):
        x = int(data[i])
        pos = bisect_left(tails, x)
        if pos == len(tails):
            tails.append(x)
        else:
            tails[pos] = x
    print(len(tails))


if __name__ == "__main__":
    main()
```
