# P23 石子合并

- **标签**：#动态规划 #区间DP
- **难度**：★★★★☆
- **来源**：洛谷 P1775 / 经典区间 DP

## 题目描述

有 n 堆石子排成一行，第 i 堆有 a_i 个石子。

每次只能选择当前相邻的两堆石子，将它们合并成一堆，本次合并的代价为这两堆石子个数之和；合并得到的新堆放在原来的位置上，其石子个数也等于这两堆石子个数之和。经过 n-1 次合并后，所有石子会合并成一堆。

总代价定义为每次合并代价之和。请计算所有合并方案中总代价的最小值。当 n = 1 时不需要合并，总代价为 0。

## 输入格式

输入只有一组数据。

第一行一个整数 n。

第二行 n 个用空格分隔的整数 a_1, a_2, …, a_n。

## 输出格式

输出一行一个整数，表示将所有石子合并成一堆的最小总代价。

## 样例输入

```text
4
4 5 9 4
```

## 样例输出

```text
44
```

## 数据范围

- 1 ≤ n ≤ 300
- 1 ≤ a_i ≤ 10^4
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 300
#define INF 1000000000000000000LL

long long dp[MAXN + 1][MAXN + 1];
long long prefix[MAXN + 1];

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 1; i <= n; ++i) {
        int a;
        scanf("%d", &a);
        prefix[i] = prefix[i - 1] + a;
    }
    // 区间 DP：枚举最后一次合并的分界点
    for (int len = 2; len <= n; ++len) {
        for (int i = 1; i + len - 1 <= n; ++i) {
            int j = i + len - 1;
            dp[i][j] = INF;
            long long sum = prefix[j] - prefix[i - 1];
            for (int k = i; k < j; ++k) {
                long long cur = dp[i][k] + dp[k + 1][j] + sum;
                if (cur < dp[i][j]) dp[i][j] = cur;
            }
        }
    }
    printf("%lld\n", dp[1][n]);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n;
    if (!(std::cin >> n)) return 0;
    std::vector<long long> prefix(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        long long a;
        std::cin >> a;
        prefix[i] = prefix[i - 1] + a;
    }
    std::vector<std::vector<long long>> dp(n + 1, std::vector<long long>(n + 1, 0));
    const long long INF = 1000000000000000000LL;
    // 区间 DP：枚举最后一次合并的分界点
    for (int len = 2; len <= n; ++len)
        for (int i = 1; i + len - 1 <= n; ++i) {
            int j = i + len - 1;
            long long sum = prefix[j] - prefix[i - 1];
            dp[i][j] = INF;
            for (int k = i; k < j; ++k)
                dp[i][j] = std::min(dp[i][j], dp[i][k] + dp[k + 1][j] + sum);
        }
    std::cout << dp[1][n] << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    a = data[1:1 + n]
    prefix = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix[i] = prefix[i - 1] + a[i - 1]
    INF = 10 ** 18
    dp = [[0] * (n + 1) for _ in range(n + 1)]
    # 区间 DP：按区间长度递增计算最小合并代价
    for length in range(2, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            s = prefix[j] - prefix[i - 1]
            best = INF
            for k in range(i, j):
                cur = dp[i][k] + dp[k + 1][j] + s
                if cur < best:
                    best = cur
            dp[i][j] = best
    print(dp[1][n])


main()
```
