# P21 零钱兑换

- **标签**：#动态规划 #完全背包
- **难度**：★★★☆☆
- **来源**：LeetCode 322 / 经典完全背包

## 题目描述

给定 n 种硬币，第 i 种硬币的面额为 c_i，每种硬币都有无限多枚。现在要恰好凑出总金额 amount，求最少需要多少枚硬币。

同一种硬币可以使用任意多枚。如果不存在任何方案能够恰好凑出 amount，则输出 -1。特别地，当 amount = 0 时不需要任何硬币，答案为 0。

## 输入格式

输入只有一组数据。

第一行两个整数 n 和 amount，中间用一个空格分隔。

第二行 n 个用空格分隔的整数 c_1, c_2, …, c_n。

## 输出格式

输出一行一个整数，表示凑出 amount 所需的最少硬币枚数；如果无法恰好凑出，则输出 -1。

## 样例输入

```text
3 11
1 2 5
```

## 样例输出

```text
3
```

## 数据范围

- 1 ≤ n ≤ 100
- 0 ≤ amount ≤ 10^4
- 1 ≤ c_i ≤ 10^4
- 硬币面额可能重复
- 输入只有一组测试数据

## 标准实现

### C

```c
#include <stdio.h>

#define MAXA 10000
#define INF 1000000000

int dp[MAXA + 1];

int main(void) {
    int n, amount;
    if (scanf("%d %d", &n, &amount) != 2) return 0;
    dp[0] = 0;
    for (int i = 1; i <= amount; ++i) dp[i] = INF;
    // 完全背包：每种硬币可使用任意多次
    for (int i = 0; i < n; ++i) {
        int c;
        scanf("%d", &c);
        for (int j = c; j <= amount; ++j)
            if (dp[j - c] + 1 < dp[j]) dp[j] = dp[j - c] + 1;
    }
    printf("%d\n", dp[amount] == INF ? -1 : dp[amount]);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    int n, amount;
    if (!(std::cin >> n >> amount)) return 0;
    const int INF = 1000000000;
    std::vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    // 完全背包：每种硬币可使用任意多次
    for (int i = 0; i < n; ++i) {
        int c;
        std::cin >> c;
        for (int j = c; j <= amount; ++j)
            dp[j] = std::min(dp[j], dp[j - c] + 1);
    }
    std::cout << (dp[amount] == INF ? -1 : dp[amount]) << '\n';
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, amount = data[0], data[1]
    coins = data[2:2 + n]
    INF = 10 ** 9
    dp = [INF] * (amount + 1)
    dp[0] = 0
    # 完全背包：每种硬币可使用任意多次
    for c in coins:
        for j in range(c, amount + 1):
            if dp[j - c] + 1 < dp[j]:
                dp[j] = dp[j - c] + 1
    print(-1 if dp[amount] == INF else dp[amount])


main()
```
