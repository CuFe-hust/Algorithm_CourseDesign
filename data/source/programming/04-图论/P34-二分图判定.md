# P34 二分图判定

- **标签**：#图论 #二分图 #染色
- **难度**：★★★☆☆
- **来源**：经典算法题（二分图判定）

## 题目描述

给定一张有 n 个结点、m 条边的无向图，结点编号为 1,2,...,n。

如果存在一种把点集划分为两个部分的方式，使得图中每条边的两个端点都分别属于这两个不同的部分，则称该图是二分图。等价地说，可以用两种颜色给每个结点染色，使每条边的两个端点颜色不同。

请判断给定的无向图是否为二分图。

图中可能存在重边（多条连接同一对结点的边）和自环（u=v 的边）。若图中存在自环，则该图一定不是二分图。

## 输入格式

第一行包含两个整数 n 和 m，分别表示结点数和无向边数。

接下来 m 行，每行包含两个整数 u 和 v（1 <= u,v <= n），表示结点 u 与结点 v 之间有一条无向边。

输入只有一组数据。

## 输出格式

输出一行：如果该图是二分图，输出 `Yes`；否则输出 `No`。

## 样例输入

```text
4 4
1 2
1 3
2 4
3 4
```

## 样例输出

```text
Yes
```

## 数据范围

- 1 <= n <= 10^5
- 0 <= m <= 2 x 10^5
- 1 <= u,v <= n
- 允许重边和自环。

## 标准实现

### C

```c
#include <stdio.h>

#define MAXN 100005
#define MAXM 400005

int head[MAXN], nxt[MAXM], to[MAXM], ecnt;
int color[MAXN], que[MAXN];

/* 无向边按正反两个方向各存一次 */
void addEdge(int u, int v) {
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    for (int i = 0; i < m; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        addEdge(u, v);
        addEdge(v, u);
    }
    /* 1、2 表示两种颜色，0 表示尚未染色 */
    for (int s = 1; s <= n; ++s) {
        if (color[s]) continue;
        color[s] = 1;
        int front = 0, back = 0;
        que[back++] = s;
        while (front < back) {
            int u = que[front++];
            for (int e = head[u]; e; e = nxt[e]) {
                int v = to[e];
                if (color[v] == 0) {
                    color[v] = 3 - color[u];
                    que[back++] = v;
                } else if (color[v] == color[u]) {
                    printf("No\n");
                    return 0;
                }
            }
        }
    }
    printf("Yes\n");
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    // 邻接表存无向图
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    // 1、2 表示两种颜色，0 表示尚未染色
    vector<int> color(n + 1, 0);
    for (int s = 1; s <= n; ++s) {
        if (color[s]) continue;
        color[s] = 1;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (color[v] == 0) {
                    color[v] = 3 - color[u];
                    q.push(v);
                } else if (color[v] == color[u]) {
                    cout << "No\n";
                    return 0;
                }
            }
        }
    }
    cout << "Yes\n";
    return 0;
}
```

### Python

```python
import sys
from collections import deque


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, m = data[0], data[1]
    adj = [[] for _ in range(n + 1)]
    pos = 2
    for _ in range(m):
        u, v = data[pos], data[pos + 1]
        pos += 2
        adj[u].append(v)
        adj[v].append(u)

    # 1、2 表示两种颜色，0 表示尚未染色
    color = [0] * (n + 1)
    for s in range(1, n + 1):
        if color[s]:
            continue
        color[s] = 1
        # 对每个连通块做 BFS 染色
        q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    sys.stdout.write("No\n")
                    return
    sys.stdout.write("Yes\n")


main()
```
