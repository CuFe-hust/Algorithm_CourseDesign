# P27 负权环判定

- **标签**：#图论 #Bellman-Ford #负环
- **难度**：★★★★☆
- **来源**：经典算法题（负权环判定）

## 题目描述

给定一个包含 \(n\) 个结点、\(m\) 条边的有向图，结点编号为 \(1\) 到 \(n\)。每条边都有一个整数边权，边权可能为负数。请判断整个图中是否存在负权环。

负权环是指一个至少包含一条边的有向环，其环上所有边的边权之和严格小于 \(0\)。自环也被视为环。负权环可以位于图中的任意位置，不要求从某个特定结点可达。

图中允许重边和自环。若存在负权环输出 `Yes`，否则输出 `No`。

## 输入格式

第一行包含两个整数 \(n\) 和 \(m\)，分别表示结点数和边数。

接下来 \(m\) 行，每行包含三个整数 \(u\)、\(v\)、\(w\)，表示一条从 \(u\) 指向 \(v\)、边权为 \(w\) 的有向边。

本题只有一组测试数据。

## 输出格式

输出一行。若图中存在负权环，输出 `Yes`；否则输出 `No`。

## 样例输入

```text
3 3
1 2 1
2 3 -3
3 1 1
```

## 样例输出

```text
Yes
```

## 数据范围

- \(1 <= n <= 2000\)，\(0 <= m <= 5000\)。
- \(1 <= u,v <= n\)，\(-10^9 <= w <= 10^9\)。
- 允许重边和自环，不保证图连通。
- 图中可能有负权边，但不会出现边权之和超出 64 位整数范围的情况。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;

    static int eu[5005], ev[5005];
    static long long ew[5005], dist[2005];
    for (int i = 0; i < m; i++) {
        scanf("%d %d %lld", &eu[i], &ev[i], &ew[i]);
    }

    // 所有点初始距离为 0，相当于加入一个到各点权值为 0 的超级源点
    for (int pass = 1; pass <= n - 1; pass++) {
        int changed = 0;
        for (int i = 0; i < m; i++) {
            long long nd = dist[eu[i]] + ew[i];
            if (nd < dist[ev[i]]) {
                dist[ev[i]] = nd;
                changed = 1;
            }
        }
        if (!changed) break;
    }

    // 再进行一轮松弛，仍能更新说明存在负权环
    for (int i = 0; i < m; i++) {
        if (dist[eu[i]] + ew[i] < dist[ev[i]]) {
            puts("Yes");
            return 0;
        }
    }
    puts("No");
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Edge {
    int u, v;
    long long w;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    vector<long long> dist(n + 1, 0);
    // 所有点初始距离为 0，可检测任意位置上的负权环
    for (int pass = 1; pass <= n - 1; pass++) {
        bool changed = false;
        for (const Edge &e : edges) {
            if (dist[e.u] + e.w < dist[e.v]) {
                dist[e.v] = dist[e.u] + e.w;
                changed = true;
            }
        }
        if (!changed) break;
    }

    for (const Edge &e : edges) {
        if (dist[e.u] + e.w < dist[e.v]) {
            cout << "Yes\n";
            return 0;
        }
    }
    cout << "No\n";
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, m = data[0], data[1]
    edges = []
    p = 2
    for _ in range(m):
        u, v, w = data[p], data[p + 1], data[p + 2]
        p += 3
        edges.append((u, v, w))

    dist = [0] * (n + 1)
    # 所有点初始距离为 0，可检测任意位置上的负权环
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            nd = dist[u] + w
            if nd < dist[v]:
                dist[v] = nd
                changed = True
        if not changed:
            break

    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            print("Yes")
            return
    print("No")


if __name__ == "__main__":
    main()
```
