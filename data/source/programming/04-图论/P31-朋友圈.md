# P31 朋友圈

- **标签**：#图论 #并查集
- **难度**：★★☆☆☆
- **来源**：经典算法题（并查集 / 亲戚）

## 题目描述

有 n 个人，编号为 1 到 n。已知其中存在 m 对朋友关系，每对关系由两个编号 u 和 v 给出，表示 u 与 v 是朋友。

朋友关系是相互的，并且具有传递性：如果 A 与 B 是朋友，B 与 C 是朋友，那么 A 与 C 也属于同一个朋友圈。也就是说，只要两个人能通过若干条朋友关系间接相连，他们就属于同一个朋友圈；一个人自己也属于包含他的那个朋友圈。

现在给出 q 次询问，每次询问两个人 a 和 b，请判断他们是否属于同一个朋友圈。

## 输入格式

第一行包含两个整数 n 和 m，分别表示人数和朋友关系数。

接下来 m 行，每行包含两个整数 u 和 v，表示 u 与 v 是朋友。当 m = 0 时，这一部分为空。

接下来一行包含一个整数 q，表示询问次数。

接下来 q 行，每行包含两个整数 a 和 b，表示一次询问。

## 输出格式

输出 q 行，依次对应每次询问。若 a 与 b 属于同一个朋友圈，输出 `Yes`；否则输出 `No`。输出区分大小写。

## 样例输入
```text
5 3
1 2
2 3
4 5
2
1 3
1 4
```
## 样例输出
```text
Yes
No
```
## 数据范围

- 1 ≤ n ≤ 10^5
- 0 ≤ m ≤ 10^5
- 1 ≤ q ≤ 10^5
- 1 ≤ u, v, a, b ≤ n
- 朋友关系可能重复给出，也可能出现 u = v 的情形（自己与自己当然是朋友），这些情况不影响答案

## 标准实现

### C
```c
#include <stdio.h>

#define MAXN 100005

static int parent[MAXN], rnk[MAXN];

/* 查找根结点，带路径压缩 */
int find(int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    for (int i = 1; i <= n; i++) {
        parent[i] = i;
        rnk[i] = 0;
    }
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        /* 按秩合并 */
        int ru = find(u), rv = find(v);
        if (ru != rv) {
            if (rnk[ru] < rnk[rv]) {
                int t = ru;
                ru = rv;
                rv = t;
            }
            parent[rv] = ru;
            if (rnk[ru] == rnk[rv]) rnk[ru]++;
        }
    }
    int q;
    scanf("%d", &q);
    while (q--) {
        int a, b;
        scanf("%d %d", &a, &b);
        puts(find(a) == find(b) ? "Yes" : "No");
    }
    return 0;
}
```

### C++
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct DSU {
    vector<int> fa, sz;
    explicit DSU(int n) : fa(n + 1), sz(n + 1, 1) {
        for (int i = 1; i <= n; i++) fa[i] = i;
    }
    // 路径压缩查找
    int find(int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    }
    // 按大小合并
    void unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        fa[b] = a;
        sz[a] += sz[b];
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;
    DSU dsu(n);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        dsu.unite(u, v);
    }
    int q;
    cin >> q;
    while (q--) {
        int a, b;
        cin >> a >> b;
        cout << (dsu.find(a) == dsu.find(b) ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

### Python
```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    pos = 0
    n = int(data[pos]); pos += 1
    m = int(data[pos]); pos += 1

    # 并查集：路径压缩 + 按大小合并
    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        root = x
        while parent[root] != root:
            root = parent[root]
        while parent[x] != x:
            parent[x], x = root, parent[x]
        return root

    for _ in range(m):
        u = int(data[pos]); pos += 1
        v = int(data[pos]); pos += 1
        ru = find(u)
        rv = find(v)
        if ru != rv:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
            size[ru] += size[rv]

    q = int(data[pos]); pos += 1
    out = []
    for _ in range(q):
        a = int(data[pos]); pos += 1
        b = int(data[pos]); pos += 1
        # 根相同即属于同一朋友圈
        out.append("Yes" if find(a) == find(b) else "No")
    sys.stdout.write("\n".join(out) + "\n")


main()
```
