# P30 迷宫最短路

- **标签**：#图论 #BFS #最短路
- **难度**：★★☆☆☆
- **来源**：经典算法题（迷宫最短路）

## 题目描述

给定一个 n 行 m 列的网格迷宫，行从上到下编号为 1 到 n，列从左到右编号为 1 到 m。

迷宫中的每个格子用字符表示：`.` 表示可以通行的空地，`#` 表示墙壁、不能通行。

你从左上角格子 (1,1) 出发，要走到右下角格子 (n,m)。每一步可以向上、下、左、右移动一格，移动后必须仍在迷宫范围内，且不能进入墙壁格子。求从起点到终点所需的最少步数。

## 输入格式

第一行包含两个整数 n 和 m，分别表示迷宫的行数和列数。

接下来 n 行，每行是一个长度为 m 的字符串，仅由字符 `.` 和 `#` 组成，描述迷宫的一行。

保证起点 (1,1) 和终点 (n,m) 都是 `.`。

## 输出格式

输出一行一个整数，表示从 (1,1) 到 (n,m) 的最少步数。

如果无法到达终点，输出 -1。

## 样例输入
```text
3 3
...
.#.
...
```
## 样例输出
```text
4
```
## 数据范围

- 1 ≤ n, m ≤ 1000
- 迷宫中仅包含字符 `.` 和 `#`，每行长度恰好为 m
- 起点 (1,1) 与终点 (n,m) 保证为 `.`
- 当 n = m = 1 时起点即终点，最少步数为 0

## 标准实现

### C
```c
#include <stdio.h>

#define MAXN 1005
#define MAXQ 1000005

static char grid[MAXN][MAXN];
static int dist[MAXN][MAXN];
static int que[MAXQ];

int main(void) {
    int n, m;
    if (scanf("%d %d", &n, &m) != 2) return 0;
    for (int i = 0; i < n; i++) scanf("%s", grid[i]);

    /* dist 为 -1 表示该格子尚未访问 */
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) dist[i][j] = -1;

    const int dx[4] = {1, -1, 0, 0};
    const int dy[4] = {0, 0, 1, -1};
    int head = 0, tail = 0;
    dist[0][0] = 0;
    que[tail++] = 0;
    /* 队列中存放格子编号 x * m + y */
    while (head < tail) {
        int cur = que[head++];
        int x = cur / m, y = cur % m;
        if (x == n - 1 && y == m - 1) break;
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (grid[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            que[tail++] = nx * m + ny;
        }
    }
    printf("%d\n", dist[n - 1][m - 1]);
    return 0;
}
```

### C++
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;
    vector<string> grid(n);
    for (int i = 0; i < n; i++) cin >> grid[i];

    // BFS 求最短路，未访问的格子距离为 -1
    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    dist[0][0] = 0;
    q.push({0, 0});  // 起点入队
    const int dx[4] = {1, -1, 0, 0};
    const int dy[4] = {0, 0, 1, -1};
    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        if (x == n - 1 && y == m - 1) break;
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (grid[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << dist[n - 1][m - 1] << "\n";
    return 0;
}
```

### Python
```python
import sys


def main():
    data = sys.stdin.buffer
    first = data.readline().split()
    if not first:
        return
    n, m = map(int, first)
    grid = [data.readline().strip() for _ in range(n)]

    # BFS 求最少步数，队列中存放格子编号 x * m + y
    dist = [[-1] * m for _ in range(n)]
    dist[0][0] = 0
    que = [0]
    head = 0
    while head < len(que):
        cur = que[head]
        head += 1
        x, y = divmod(cur, m)
        if x == n - 1 and y == m - 1:
            break
        nd = dist[x][y] + 1
        for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
            # 46 是字符 '.' 的 ASCII 码
            if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] == 46 and dist[nx][ny] < 0:
                dist[nx][ny] = nd
                que.append(nx * m + ny)

    print(dist[n - 1][m - 1])


main()
```
