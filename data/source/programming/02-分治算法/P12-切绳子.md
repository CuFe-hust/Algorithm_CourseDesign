# P12 切绳子

- **标签**：#分治算法 #二分答案
- **难度**：★★★☆☆
- **来源**：洛谷 P2440（木材加工）改编

## 题目描述

有 n 根绳子，第 i 根绳子的长度为 L_i 厘米。现在要从这些绳子中切出至少 k 段长度相同的绳子，要求每段的长度都是正整数厘米。

切割规则如下：

- 每一段都必须从某一根完整的绳子上切下，同一根绳子可以切出多段。
- 不要求使用所有绳子，也不要求把某根绳子用完；剩余的部分直接丢弃。
- 不同绳子的剩余部分不能拼接在一起。

请你求出能切出的每段绳子的最大整数长度。如果不存在正整数长度 x，使得能够切出至少 k 段长度为 x 的绳子，则输出 0。

## 输入格式

输入共两行：

- 第一行包含两个整数 n 和 k，中间用一个空格分隔。
- 第二行包含 n 个整数 L_1, L_2, ..., L_n，相邻两个整数之间用一个空格分隔。

输入只有一组测试数据。

## 输出格式

输出一行一个整数，表示每段绳子的最大整数长度；若一段也切不出来，输出 0。

## 样例输入
```text
4 11
802 743 457 539
```

## 样例输出
```text
200
```

## 数据范围

- 1 <= n <= 10^5
- 1 <= k <= 10^5
- 1 <= L_i <= 10^6

每段绳子的长度必须是正整数厘米，答案一定落在 [0, max(L_i)] 内。

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n, k;
    scanf("%d %d", &n, &k);
    int *L = (int *)malloc(sizeof(int) * n);
    int maxL = 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &L[i]);
        if (L[i] > maxL) maxL = L[i];
    }
    /* 二分答案：答案在 [0, maxL] 中，0 表示无解 */
    int lo = 0, hi = maxL + 1;
    while (lo + 1 < hi) {
        int mid = (lo + hi) / 2;
        long long sum = 0;
        for (int i = 0; i < n; i++) {
            sum += L[i] / mid;
            if (sum >= k) break;
        }
        if (sum >= k) lo = mid;
        else hi = mid;
    }
    printf("%d\n", lo);
    free(L);
    return 0;
}
```

### Python

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    n, k = data[0], data[1]
    L = data[2:2 + n]
    # 二分答案：答案在 [0, max(L)] 中，0 表示无解
    lo, hi = 0, max(L) + 1
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        cnt = 0
        for x in L:
            cnt += x // mid
            if cnt >= k:
                break
        if cnt >= k:
            lo = mid
        else:
            hi = mid
    print(lo)


main()
```
