# P15 大整数乘法

- **标签**：#分治算法 #高精度 #Karatsuba
- **难度**：★★★★☆
- **来源**：经典算法题（大整数乘法）

## 题目描述

给出两个非负整数 a 和 b，请计算它们的乘积 a × b。

两个整数都以十进制形式给出，各自的位数都可能达到 200 位，乘积的位数可能超过 400 位，已经超出普通整型的表示范围。请使用高精度方式完成计算，保证结果的每一位都准确无误。

## 输入格式

输入共两行，只有一组数据。

第一行是一个非负整数的十进制表示，即 a；第二行是一个非负整数的十进制表示，即 b。

每个数的表示只包含数字 0 到 9，不含正负号、小数点、千位分隔符，也不含多余的前导零；数值为 0 时写作单个 0。每个数的长度不超过 200。

## 输出格式

输出一行，包含一个十进制整数，表示 a × b 的精确结果。

结果中不得含有前导零；若乘积为 0，则输出单个 0。行末需要换行。

## 样例输入

```text
123456789
987654321
```

## 样例输出

```text
121932631112635269
```

## 数据范围

- 1 ≤ len(a) ≤ 200，1 ≤ len(b) ≤ 200，其中 len(x) 表示整数 x 的十进制表示的位数。
- a、b 均为非负整数，且十进制表示中不含多余前导零。
- 乘积 a × b 的十进制位数不超过 400。
- 输入只有一组数据。

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

static char a[205], b[205];
static int res[410];

int main(void) {
    if (scanf("%204s", a) != 1) return 0;
    if (scanf("%204s", b) != 1) return 0;
    int la = (int)strlen(a), lb = (int)strlen(b);
    memset(res, 0, sizeof(res));
    /* 从低位到高位逐位相乘，先按位累加，不急于进位 */
    for (int i = la - 1; i >= 0; i--) {
        int x = a[i] - '0';
        for (int j = lb - 1; j >= 0; j--) {
            res[(la - 1 - i) + (lb - 1 - j)] += x * (b[j] - '0');
        }
    }
    int len = la + lb;
    /* 从低位向高位统一处理进位 */
    for (int k = 0; k < len; k++) {
        if (res[k] >= 10) {
            res[k + 1] += res[k] / 10;
            res[k] %= 10;
        }
    }
    int p = len;
    while (p > 0 && res[p] == 0) p--;
    for (int k = p; k >= 0; k--) putchar('0' + res[k]);
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

static const int BASE = 10000;
typedef std::vector<int> Big;  /* 小端存储，每一位是 0..9999 的四位十进制块 */

static Big norm(Big a) {
    while (a.size() > 1 && a.back() == 0) a.pop_back();
    return a;
}

static Big addBig(const Big &a, const Big &b) {
    Big c(std::max(a.size(), b.size()) + 1, 0);
    int carry = 0;
    for (size_t i = 0; i < c.size(); i++) {
        int s = carry;
        if (i < a.size()) s += a[i];
        if (i < b.size()) s += b[i];
        c[i] = s % BASE;
        carry = s / BASE;
    }
    return norm(c);
}

static Big subBig(const Big &a, const Big &b) {
    Big c(a.size(), 0);
    int borrow = 0;
    for (size_t i = 0; i < a.size(); i++) {
        int s = a[i] - borrow - (i < b.size() ? b[i] : 0);
        if (s < 0) { s += BASE; borrow = 1; } else borrow = 0;
        c[i] = s;
    }
    return norm(c);
}

static Big mulSchool(const Big &a, const Big &b) {
    std::vector<long long> t(a.size() + b.size(), 0);
    for (size_t i = 0; i < a.size(); i++)
        for (size_t j = 0; j < b.size(); j++)
            t[i + j] += (long long)a[i] * b[j];
    Big c(t.size(), 0);
    long long carry = 0;
    for (size_t i = 0; i < t.size(); i++) {
        long long cur = t[i] + carry;
        c[i] = (int)(cur % BASE);
        carry = cur / BASE;
    }
    return norm(c);
}

/* 把 b 左移 shift 位后加到 a 上 */
static Big addShift(Big a, const Big &b, size_t shift) {
    size_t need = b.size() + shift;
    if (a.size() < need) a.resize(need, 0);
    int carry = 0;
    for (size_t i = 0; i < b.size() || carry; i++) {
        if (i + shift >= a.size()) a.resize(i + shift + 1, 0);
        int s = a[i + shift] + carry + (i < b.size() ? b[i] : 0);
        a[i + shift] = s % BASE;
        carry = s / BASE;
    }
    return norm(a);
}

/* Karatsuba 分治乘法：a = a1*BASE^m + a0，b = b1*BASE^m + b0 */
static Big mul(const Big &a, const Big &b) {
    size_t n = std::max(a.size(), b.size());
    if (n <= 32) return mulSchool(a, b);
    size_t m = n / 2;
    Big a0, a1, b0, b1;
    a0.assign(a.begin(), a.begin() + std::min(m, a.size()));
    b0.assign(b.begin(), b.begin() + std::min(m, b.size()));
    a1 = (a.size() > m) ? Big(a.begin() + m, a.end()) : Big(1, 0);
    b1 = (b.size() > m) ? Big(b.begin() + m, b.end()) : Big(1, 0);
    Big z0 = mul(a0, b0);
    Big z2 = mul(a1, b1);
    Big z1 = subBig(subBig(mul(addBig(a0, a1), addBig(b0, b1)), z0), z2);
    Big res = addShift(z0, z1, m);
    res = addShift(res, z2, 2 * m);
    return norm(res);
}

static Big parse(const std::string &s) {
    Big r;
    for (int i = (int)s.size(); i > 0; i -= 4) {
        int st = std::max(0, i - 4), v = 0;
        for (int j = st; j < i; j++) v = v * 10 + (s[j] - '0');
        r.push_back(v);
    }
    return norm(r);
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    std::string sa, sb;
    if (!(std::cin >> sa)) return 0;
    std::cin >> sb;
    Big p = mul(parse(sa), parse(sb));
    std::cout << p.back();
    for (int i = (int)p.size() - 2; i >= 0; i--) {
        std::cout.width(4);
        std::cout.fill('0');
        std::cout << p[i];
    }
    std::cout << '\n';
    return 0;
}
```
