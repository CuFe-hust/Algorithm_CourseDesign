# P10 逆序对

- **标签**：#分治算法 #归并排序 #逆序对
- **难度**：★★★☆☆
- **来源**：经典算法题 / 洛谷 P1908

## 题目描述

给定一个长度为 n 的整数序列 a_1, a_2, ..., a_n，下标从 1 开始。如果存在两个下标 i, j 满足 i < j 且 a_i > a_j，则称 (i, j) 是序列的一个逆序对。

请你统计序列中逆序对的总数。序列中可能存在相同的元素，此时 a_i = a_j，不构成逆序对。

本题要求使用分治算法（归并排序的思想）完成，时间复杂度为 O(n log n)。

## 输入格式

输入共两行：

- 第一行包含一个整数 n。
- 第二行包含 n 个整数 a_1, a_2, ..., a_n，相邻两个整数之间用一个空格分隔。

输入只有一组测试数据，行末没有多余空格。

## 输出格式

输出一行一个整数，表示序列中逆序对的总数。

## 样例输入
```text
5
5 4 3 2 1
```

## 样例输出
```text
10
```

## 数据范围

- 1 <= n <= 5 × 10^5
- |a_i| <= 10^9

逆序对总数可能超过 32 位有符号整数的表示范围，最大可达 5 × 10^5 × (5 × 10^5 - 1) / 2 = 124999750000，请使用 64 位整数存储答案（C/C++ 使用 long long，Python 的整数没有此限制）。

输入规模较大，建议使用效率较高的读入方式。

## 标准实现

### C

```c
#include <stdio.h>
#include <stdlib.h>

static long long *tmp; /* 归并辅助数组 */
static long long cnt;  /* 逆序对总数 */

/* 归并排序 [l, r)，合并时统计跨越中点的逆序对 */
static void merge_count(long long *a, int l, int r) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    merge_count(a, l, m);
    merge_count(a, m, r);
    int i = l, j = m, k = l;
    while (i < m && j < r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            cnt += m - i;
            tmp[k++] = a[j++];
        }
    }
    while (i < m) tmp[k++] = a[i++];
    while (j < r) tmp[k++] = a[j++];
    for (i = l; i < r; i++) a[i] = tmp[i];
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    long long *a = (long long *)malloc(sizeof(long long) * n);
    tmp = (long long *)malloc(sizeof(long long) * n);
    for (int i = 0; i < n; i++) scanf("%lld", &a[i]);
    cnt = 0;
    merge_count(a, 0, n);
    printf("%lld\n", cnt);
    free(a);
    free(tmp);
    return 0;
}
```

```cpp
            tmp[k++] = a[j++];

    while (i < m) tmp[k++] = a[i++];
```

### Python

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    tmp = [0] * n
    cnt = 0

    # 归并排序，合并时累加逆序对
    def merge_count(l, r):
        nonlocal cnt
        if r - l <= 1:
            return
        m = (l + r) // 2
        merge_count(l, m)
        merge_count(m, r)
        i, j, k = l, m, l
        while i < m and j < r:
            if a[i] <= a[j]:
                tmp[k] = a[i]
                i += 1
            else:
                cnt += m - i
                tmp[k] = a[j]
                j += 1
            k += 1
        while i < m:
            tmp[k] = a[i]
            i += 1
            k += 1
        while j < r:
            tmp[k] = a[j]
            j += 1
            k += 1
        a[l:r] = tmp[l:r]

    merge_count(0, n)
    print(cnt)


main()
```
