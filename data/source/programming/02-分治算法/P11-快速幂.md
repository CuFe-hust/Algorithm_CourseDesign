# P11 快速幂

- **标签**：#分治算法 #快速幂 #数论
- **难度**：★★☆☆☆
- **来源**：经典算法题 / 洛谷 P1226

## 题目描述

给定三个整数 a, b, p，请你计算 a^b mod p，也就是 a 的 b 次方除以 p 后得到的余数。指数 b 可能非常大，要求使用快速幂算法，在 O(log b) 次乘法内完成计算。

本题特别规定：

- 对任意非负整数 a，都有 a^0 = 1，包括 0^0 = 1。
- 当 p = 1 时，任何整数除以 1 的余数都是 0，因此此时答案恒为 0。

这里的 mod 表示取余数，答案应当落在 [0, p - 1] 范围内。

## 输入格式

输入只有一行，包含三个整数 a, b, p，相邻两个整数之间用一个空格分隔。

输入只有一组测试数据。

## 输出格式

输出一行一个整数，表示 a^b mod p 的值，结果在 [0, p - 1] 内。

## 样例输入
```text
2 10 1000
```

## 样例输出
```text
24
```

## 数据范围

- 0 <= a <= 10^9
- 0 <= b <= 10^18
- 1 <= p <= 10^9 + 7

b 可能超过 32 位整数的表示范围，请使用 64 位整数读入（C/C++ 使用 long long，Python 的整数没有此限制）。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    long long a, b, p;
    scanf("%lld %lld %lld", &a, &b, &p);
    long long ans = 1 % p; /* p 为 1 时答案为 0 */
    a %= p;
    /* 快速幂：按二进制位逐位平方、相乘 */
    while (b > 0) {
        if (b & 1) ans = ans * a % p;
        a = a * a % p;
        b >>= 1;
    }
    printf("%lld\n", ans);
    return 0;
}
```

import sys


def main():
    a, b, p = map(int, sys.stdin.buffer.read().split())
    ans = 1 % p  # p 为 1 时答案为 0
    a %= p
    # 快速幂：按二进制位逐位平方、相乘
    while b > 0:
        if b & 1:
            ans = ans * a % p
        a = a * a % p
        b >>= 1
    print(ans)


main()
