# P14 汉诺塔

- **标签**：#分治算法 #递归
- **难度**：★★☆☆☆
- **来源**：经典算法题（Tower of Hanoi）

## 题目描述

有三根柱子，分别记为 A、B、C。初始时有 n 个大小互不相同的圆盘全部套在柱子 A 上，并且按照小盘在上、大盘在下的顺序叠放。另外两根柱子 B 和 C 初始为空。

每次操作只能移动某根柱子最上面的一个圆盘，把它放到另一根柱子上。移动过程中，任何时刻都不能把较大的圆盘放在较小的圆盘上面；目标柱子为空或者其最上面的圆盘比待移动的圆盘大时，才可以放置。

目标是把全部 n 个圆盘都移动到柱子 C 上，并保持小盘在上、大盘在下的顺序。请求出最少的移动次数，并输出对应的移动过程。对于给定的 n，最短移动方案是唯一的。

## 输入格式

输入只有一行，包含一个整数 n。

输入只有一组测试数据。

## 输出格式

输出共 2^n 行：

- 第一行一个整数，表示最少移动次数，即 2^n - 1。
- 接下来 2^n - 1 行，每行一条移动指令，格式严格为 `X -> Y`，其中 X、Y 均为 A、B、C 之一，表示把柱子 X 最上面的圆盘移动到柱子 Y。箭头 `->` 的左右各有一个空格，行末不能有多余空格。

## 样例输入
```text
2
```

## 样例输出
```text
3
A -> B
A -> C
B -> C
```

## 数据范围

- 1 <= n <= 10
- 最少移动次数 2^n - 1 不超过 1023

输出的移动过程必须合法，并且恰好包含 2^n - 1 条移动指令。

## 标准实现

### C

```c
#include <stdio.h>

/* 把 n 个圆盘从 from 移到 to，via 作为中转柱 */
void hanoi(int n, char from, char via, char to) {
    if (n == 0) return;
    hanoi(n - 1, from, to, via);
    printf("%c -> %c\n", from, to);
    hanoi(n - 1, via, from, to);
}

int main(void) {
    int n;
    scanf("%d", &n);
    printf("%d\n", (1 << n) - 1);
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
```

### C++

```cpp
#include <iostream>
using namespace std;

/* 把 n 个圆盘从 from 移到 to，via 作为中转柱 */
void hanoi(int n, char from, char via, char to) {
    if (n == 0) return;
    hanoi(n - 1, from, to, via);
    cout << from << " -> " << to << '\n';
    hanoi(n - 1, via, from, to);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << (1 << n) - 1 << '\n';
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
```

### Python

```python
import sys


# 把 n 个圆盘从 a 移到 c，b 作为中转柱
def hanoi(n, a, b, c, out):
    if n == 0:
        return
    hanoi(n - 1, a, c, b, out)
    out.append(a + " -> " + c)
    hanoi(n - 1, b, a, c, out)


def main():
    n = int(sys.stdin.buffer.read())
    out = [str((1 << n) - 1)]
    hanoi(n, "A", "B", "C", out)
    sys.stdout.write("\n".join(out) + "\n")


main()
```
