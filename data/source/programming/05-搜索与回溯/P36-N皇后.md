# P36 N皇后

- **标签**：#搜索与回溯 #N皇后
- **难度**：★★★☆☆
- **来源**：经典算法题（N 皇后）

## 题目描述

在 n x n 的棋盘上放置 n 个皇后，使得任意两个皇后都不在同一行、同一列或同一条斜线上。这里的斜线包括两条对角线方向上的所有格子。

求满足条件的摆放方案总数。两个方案不同，当且仅当存在至少一行，两个方案中该行皇后所在的列不同。

## 输入格式

一行一个整数 n。

## 输出格式

一行一个整数，表示合法摆放方案的总数。如果不存在合法方案，输出 `0`。

## 样例输入

```text
8
```

## 样例输出

```text
92
```

## 数据范围

1 <= n <= 12。

## 标准实现

### C

```c
#include <stdio.h>
#include <stdbool.h>

int n, ans;
bool col[15], diag1[30], diag2[30];

// 逐行放置皇后，用列与两条对角线判重
void dfs(int row) {
    if (row == n + 1) {
        ans++;
        return;
    }
    for (int c = 1; c <= n; c++) {
        if (!col[c] && !diag1[row + c] && !diag2[row - c + n]) {
            col[c] = diag1[row + c] = diag2[row - c + n] = true;
            dfs(row + 1);
            col[c] = diag1[row + c] = diag2[row - c + n] = false;
        }
    }
}

int main(void) {
    if (scanf("%d", &n) != 1) return 0;
    dfs(1);
    printf("%d\n", ans);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n, ans = 0;
vector<bool> col, diag1, diag2;

// 一行只放一个皇后，逐行搜索并累计方案数
void dfs(int row) {
    if (row == n + 1) {
        ++ans;
        return;
    }
    for (int c = 1; c <= n; ++c) {
        int d1 = row + c, d2 = row - c + n;
        if (!col[c] && !diag1[d1] && !diag2[d2]) {
            col[c] = diag1[d1] = diag2[d2] = true;
            dfs(row + 1);
            col[c] = diag1[d1] = diag2[d2] = false;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    col.assign(n + 1, false);
    diag1.assign(2 * n + 1, false);
    diag2.assign(2 * n + 1, false);
    dfs(1);
    cout << ans << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    n = int(sys.stdin.buffer.read().split()[0])
    col = [False] * (n + 1)
    d1 = [False] * (2 * n + 1)
    d2 = [False] * (2 * n + 1)
    ans = 0

    # 逐行搜索，row-c+n 用于避免负下标
    def dfs(row):
        nonlocal ans
        if row > n:
            ans += 1
            return
        for c in range(1, n + 1):
            a, b = row + c, row - c + n
            if not col[c] and not d1[a] and not d2[b]:
                col[c] = d1[a] = d2[b] = True
                dfs(row + 1)
                col[c] = d1[a] = d2[b] = False

    dfs(1)
    sys.stdout.write(str(ans) + "\n")

main()
```
