# P39 括号生成

- **标签**：#搜索与回溯 #括号生成
- **难度**：★★★☆☆
- **来源**：LeetCode 22 / 经典回溯

## 题目描述

给定括号对数 n，请生成所有由 n 个左括号 `(` 和 n 个右括号 `)` 组成的合法括号序列。

一个括号序列合法，当且仅当它满足以下两个条件：

- 序列中左括号和右括号的总数都等于 n；
- 任意一个前缀中，左括号的数量都不少于右括号的数量。

所有序列按字典序从小到大输出，每行一个。按 ASCII 码比较，字符 `(` 小于 `)`。

## 输入格式

一行一个整数 n。

## 输出格式

每行输出一个合法括号序列，共 n 对括号。当 n=0 时，空串是唯一的合法序列，输出恰好一个空行（即只输出一个换行符）。

## 样例输入

```text
3
```

## 样例输出

```text
((()))
(()())
(())()
()(())
()()()
```

## 数据范围

0 <= n <= 8。

## 标准实现

### C

```c
#include <stdio.h>

int n;
char seq[20];

// 优先放左括号，保证按字典序输出
void dfs(int pos, int left, int right) {
    if (pos == 2 * n) {
        seq[pos] = '\0';
        printf("%s\n", seq);
        return;
    }
    if (left < n) {
        seq[pos] = '(';
        dfs(pos + 1, left + 1, right);
    }
    if (right < left) {
        seq[pos] = ')';
        dfs(pos + 1, left, right + 1);
    }
}

int main(void) {
    if (scanf("%d", &n) != 1) return 0;
    dfs(0, 0, 0);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <string>
using namespace std;

int n;
string seq;

// 左右括号数量均不超过 n，且右括号数不能超过左括号
void dfs(int left, int right) {
    if ((int)seq.size() == 2 * n) {
        cout << seq << '\n';
        return;
    }
    if (left < n) {
        seq.push_back('(');
        dfs(left + 1, right);
        seq.pop_back();
    }
    if (right < left) {
        seq.push_back(')');
        dfs(left, right + 1);
        seq.pop_back();
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    dfs(0, 0);
    return 0;
}
```

### Python

```python
import sys

def main():
    n = int(sys.stdin.buffer.read().split()[0])
    out = []
    chars = []

    # 先尝试左括号，得到字典序；n=0 时输出一个空行
    def dfs(left, right):
        if len(chars) == 2 * n:
            out.append("".join(chars))
            return
        if left < n:
            chars.append("(")
            dfs(left + 1, right)
            chars.pop()
        if right < left:
            chars.append(")")
            dfs(left, right + 1)
            chars.pop()

    dfs(0, 0)
    sys.stdout.write("\n".join(out) + "\n")

main()
```
