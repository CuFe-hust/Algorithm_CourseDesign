# P40 单词搜索

- **标签**：#搜索与回溯 #DFS #网格
- **难度**：★★★☆☆
- **来源**：LeetCode 79

## 题目描述

给定一个由小写英文字母组成的 n 行 m 列字符网格，以及一个仅由小写英文字母组成的单词 word。请判断能否在网格中找到一条路径，使得路径上依次经过的字符拼接起来恰好等于 word。

路径需满足以下规则：

- 起点可以是网格中的任意一个格子；
- 每一步只能从当前格子移动到上、下、左、右四个方向相邻的格子，不能移出网格；
- 路径上同一个格子至多经过一次；
- 路径经过的格子数恰好等于 word 的长度，按经过顺序读出的字符必须与 word 的每个字符逐一对应。

约定：网格第 i 行第 j 列的字符记为 board[i][j]，其中行、列下标都从 0 开始计数，即 0 ≤ i ≤ n − 1、0 ≤ j ≤ m − 1。

本题的输入只有一组数据。

## 输入格式

第一行包含两个整数 n 和 m，分别表示网格的行数和列数，两数之间用一个空格隔开。

接下来 n 行，每行是一个长度为 m 的字符串，仅由小写英文字母组成，其中第 i 个字符串表示网格的第 i 行。

最后一行是一个字符串 word，仅由小写英文字母组成，表示需要查找的单词。

## 输出格式

输出一行。如果存在满足条件的路径，输出 Yes；否则输出 No。

注意输出的大小写必须与上述规定完全一致，行末需要换行。

## 样例输入

```text
3 4
abce
sfcs
adee
abcced
```

## 样例输出

```text
Yes
```

## 数据范围

- 1 ≤ n ≤ 6，1 ≤ m ≤ 6，网格中格子总数为 n × m。
- 1 ≤ len(word) ≤ n × m ≤ 36，其中 len(word) 表示单词的字符个数。
- 网格中每个字符与单词中每个字符都只可能是小写英文字母 a 到 z。
- 输入保证每行恰好有 m 个字符，且输入只有一组数据。

## 标准实现

### C

```c
#include <stdio.h>
#include <string.h>

static int n, m, wl;
static char grid[8][8];
static int vis[8][8];
static char word[64];
static const int dx[4] = {-1, 1, 0, 0};
static const int dy[4] = {0, 0, -1, 1};

static int dfs(int x, int y, int k) {
    if (k == wl) return 1;
    if (x < 0 || x >= n || y < 0 || y >= m) return 0;
    if (vis[x][y] || grid[x][y] != word[k]) return 0;
    vis[x][y] = 1;
    for (int d = 0; d < 4; d++) {
        if (dfs(x + dx[d], y + dy[d], k + 1)) {
            vis[x][y] = 0;
            return 1;
        }
    }
    vis[x][y] = 0;
    return 0;
}

int main(void) {
    if (scanf("%d %d", &n, &m) != 2) return 0;
    for (int i = 0; i < n; i++) scanf("%7s", grid[i]);
    scanf("%63s", word);
    wl = (int)strlen(word);
    int cnt[26] = {0};
    /* 若某个字母在单词中出现的次数超过网格，必定无解 */
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) cnt[grid[i][j] - 'a']++;
    int feasible = 1;
    for (int i = 0; i < wl; i++)
        if (--cnt[word[i] - 'a'] < 0) feasible = 0;
    int ok = 0;
    if (feasible) {
        for (int i = 0; i < n && !ok; i++)
            for (int j = 0; j < m && !ok; j++)
                if (dfs(i, j, 0)) ok = 1;
    }
    puts(ok ? "Yes" : "No");
    return 0;
}
```

### Python

```python
import sys

sys.setrecursionlimit(10000)


def main():
    data = sys.stdin.read().split()
    n, m = int(data[0]), int(data[1])
    grid = data[2:2 + n]
    word = data[2 + n]
    length = len(word)
    # 单词中某字母的出现次数超过网格时必定无解
    for c in set(word):
        if word.count(c) > sum(row.count(c) for row in grid):
            print("No")
            return
    vis = [[False] * m for _ in range(n)]
    dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

    def dfs(x, y, k):
        if k == length:
            return True
        if not (0 <= x < n and 0 <= y < m):
            return False
        if vis[x][y] or grid[x][y] != word[k]:
            return False
        vis[x][y] = True
        for dx, dy in dirs:
            if dfs(x + dx, y + dy, k + 1):
                vis[x][y] = False
                return True
        vis[x][y] = False
        return False

    ok = any(dfs(i, j, 0) for i in range(n) for j in range(m))
    print("Yes" if ok else "No")


main()
```
