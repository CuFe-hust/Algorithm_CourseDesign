# P58 扩展欧几里得

- **标签**：#数学 #数论 #扩展欧几里得
- **难度**：★★★☆☆
- **来源**：经典算法题（Extended Euclidean）

## 题目描述

给定两个正整数 a 和 b，记 g = gcd(a, b)，即 a 与 b 的最大公约数。

请计算 g，并求出一组整数 x、y，使得

a * x + b * y = g。

其中 x、y 可以是正整数、负整数或 0。同一组 a、b 可能存在多组合法的 x、y，任意一组均视为正确。

## 输入格式

一行，两个正整数 a 和 b，用一个空格分隔。

## 输出格式

一行，三个整数 g、x、y，相邻整数之间用一个空格分隔，表示最大公约数以及满足等式 a * x + b * y = g 的一组整数解。

本题采用特殊评测：只要 g 正确且 a * x + b * y = g，输出的 x、y 取任何整数都算正确。不要输出额外文字。

## 样例输入

```text
30 18
```

## 样例输出

```text
6 -1 2
```

## 数据范围

- 1 <= a, b <= 10^9
- 输入只有一组数据，没有多组询问。

## 标准实现

### C

```c
#include <stdio.h>

long long exgcd(long long a, long long b, long long *x, long long *y) {
    if (b == 0) {
        *x = 1; /* 递归边界：a*1 + 0*0 = a */
        *y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, &x1, &y1);
    *x = y1;
    *y = x1 - (a / b) * y1;
    return g;
}

int main(void) {
    long long a, b, x, y;
    scanf("%lld %lld", &a, &b);
    long long g = exgcd(a, b, &x, &y);
    printf("%lld %lld %lld\n", g, x, y);
    return 0;
}
```

### Python

```python
import sys

def exgcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = exgcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def main():
    data = sys.stdin.buffer.read().split()
    a, b = int(data[0]), int(data[1])
    g, x, y = exgcd(a, b)
    print(g, x, y)

if __name__ == "__main__":
    main()
```
