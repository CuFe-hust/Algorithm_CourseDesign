# P62 质因数分解

- **标签**：#数学 #数论
- **难度**：★★★☆☆
- **来源**：经典算法题（质因数分解）

## 题目描述

给定一个大于等于 2 的整数 n，请把它分解成若干个质因子的乘积，并按质因子从小到大的顺序输出。

输出格式规定如下：

- 若 n = p_1^{e_1} p_2^{e_2} ... p_k^{e_k}，其中 p_1 < p_2 < ... < p_k 均为质数，e_i >= 1，则输出形如 `p1^e1*p2^e2*...*pk^ek` 的一行字符串。
- 当某个质因子的指数 e_i = 1 时，只输出该质因子本身，省略 `^1`。
- 相邻两个质因子之间恰好用一个 `*` 连接，行首、行末和行末换行符之前都不能有多余字符或空格。

## 输入格式

一行一个整数 n。

## 输出格式

输出一行，为按上述规则书写的质因数分解结果。

## 样例输入

```text
360
```

## 样例输出

```text
2^3*3^2*5
```

## 数据范围

- 2 <= n <= 10^{12}
- 输入只有一组数据。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    long long n;
    if (scanf("%lld", &n) != 1) return 0;
    int first = 1;
    /* 从小到大试除，剩余部分若大于 1 则本身是质数 */
    for (long long p = 2; p * p <= n; ++p) {
        if (n % p != 0) continue;
        int e = 0;
        while (n % p == 0) {
            n /= p;
            ++e;
        }
        if (!first) putchar('*');
        first = 0;
        if (e == 1) printf("%lld", p);
        else printf("%lld^%d", p, e);
    }
    if (n > 1) {
        if (!first) putchar('*');
        printf("%lld", n);
    }
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    if (!(cin >> n)) return 0;
    bool first = true;
    /* 试除到 sqrt(n)，最后剩余的 n 若大于 1 则为质因子 */
    for (long long p = 2; p * p <= n; ++p) {
        if (n % p != 0) continue;
        int e = 0;
        while (n % p == 0) {
            n /= p;
            ++e;
        }
        if (!first) cout << '*';
        first = false;
        cout << p;
        if (e > 1) cout << '^' << e;
    }
    if (n > 1) {
        if (!first) cout << '*';
        cout << n;
    }
    cout << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    n = int(sys.stdin.buffer.read().split()[0])
    res = []
    p = 2
    # 试除到 sqrt(n)，剩余部分大于 1 时单独加入
    while p * p <= n:
        if n % p == 0:
            e = 0
            while n % p == 0:
                n //= p
                e += 1
            res.append(str(p) if e == 1 else str(p) + "^" + str(e))
        p += 1
    if n > 1:
        res.append(str(n))
    sys.stdout.write("*".join(res) + "\n")

main()
```
