# P61 进制转换

- **标签**：#数学 #进制转换
- **难度**：★★☆☆☆
- **来源**：经典算法题（进制转换）

## 题目描述

给定一个非负十进制整数 n 和一个进制 r，请把 n 转换成 r 进制表示并输出。

转换规则如下：

- 数字 0 到 9 用字符 `0` 到 `9` 表示，数字 10 到 15 用大写字母 `A` 到 `F` 表示。
- 结果中不允许出现前导零。
- 特别规定：当 n = 0 时，输出 `0`。

## 输入格式

一行两个整数 n 和 r，中间用一个空格分隔。

## 输出格式

输出一行，为一个由数字和大写字母组成的字符串，表示 n 的 r 进制表示，行末不带多余空格。

## 样例输入

```text
255 16
```

## 样例输出

```text
FF
```

## 数据范围

- 0 <= n <= 10^{18}
- 2 <= r <= 16
- 输入只有一组数据，保证 n 与 r 之间恰有一个空格。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    unsigned long long n;
    int r;
    if (scanf("%llu %d", &n, &r) != 2) return 0;
    char buf[70];
    int len = 0;
    if (n == 0) {
        printf("0\n");
        return 0;
    }
    /* 短除法逐位取余，再逆序输出 */
    while (n > 0) {
        int d = (int)(n % r);
        buf[len++] = (char)(d < 10 ? '0' + d : 'A' + d - 10);
        n /= r;
    }
    for (int i = len - 1; i >= 0; --i) putchar(buf[i]);
    putchar('\n');
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    int r;
    if (!(cin >> n >> r)) return 0;
    if (n == 0) {
        cout << 0 << '\n';
        return 0;
    }
    const string digits = "0123456789ABCDEF";
    string s;
    /* 短除法逐位取余，最后反转字符串 */
    while (n > 0) {
        s += digits[n % r];
        n /= r;
    }
    reverse(s.begin(), s.end());
    cout << s << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n, r = int(data[0]), int(data[1])
    if n == 0:
        sys.stdout.write("0\n")
        return
    digits = "0123456789ABCDEF"
    res = []
    # 短除法逐位取余，再逆序拼接
    while n > 0:
        res.append(digits[n % r])
        n //= r
    sys.stdout.write("".join(reversed(res)) + "\n")

main()
```
