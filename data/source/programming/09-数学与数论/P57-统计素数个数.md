# P57 统计素数个数

- **标签**：#数学 #数论 #筛法
- **难度**：★★☆☆☆
- **来源**：经典算法题（素数筛）

## 题目描述

给定一个正整数 n，请统计闭区间 [1, n] 内素数的个数。

素数是指大于 1 且只有 1 和自身两个正因数的正整数。特别地，1 不是素数，2 是唯一的偶素数。

本题要求使用筛法，时间复杂度应为 O(n log log n) 或 O(n)。

## 输入格式

一行，一个整数 n。

## 输出格式

一行，一个整数，表示不超过 n 的素数个数。

## 样例输入

```text
10
```

## 样例输出

```text
4
```

## 数据范围

- 1 <= n <= 10^6
- 输入只有一个整数，没有多组数据。

## 标准实现

### C

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);
    static char composite[1000001]; /* 1 表示该数已被筛掉 */
    int count = 0;
    for (int i = 2; i <= n; ++i) {
        if (!composite[i]) {
            ++count;
            for (long long j = (long long)i * i; j <= n; j += i) {
                composite[j] = 1;
            }
        }
    }
    printf("%d\n", count);
    return 0;
}
```

### C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<char> composite(n + 1, 0); /* 1 表示该数已被筛掉 */
    int count = 0;
    for (int i = 2; i <= n; ++i) {
        if (!composite[i]) {
            ++count;
            for (long long j = 1LL * i * i; j <= n; j += i) {
                composite[j] = 1;
            }
        }
    }
    cout << count << '\n';
    return 0;
}
```

### Python

```python
import sys

def main():
    n = int(sys.stdin.buffer.read().split()[0])
    composite = bytearray(n + 1)
    count = 0
    for i in range(2, n + 1):
        if not composite[i]:
            count += 1
            if i * i <= n:  # 用切片批量标记 i 的倍数
                composite[i * i:n + 1:i] = b'\x01' * (((n - i * i) // i) + 1)
    print(count)

if __name__ == "__main__":
    main()
```
