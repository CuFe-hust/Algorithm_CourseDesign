# UI/UX Pro Max 对照版

以 6092997 为基线。使用 UI/UX Pro Max 的 education LMS academic dashboard 设计系统检索和 Vue forms 指南。采用平面、浅青色、较高对比的教学工作台。面向大学课程，选用中文系统字体。教师菜单按课程管理、评分与分析、代码检查分组。登录页使用双栏，大屏保留课程识别，窄屏把登录表单放在课程名称下方。删除重复眉题和标语，加入密码显隐、清晰的首次提交按钮和保留版本时的状态提示。

本机 Edge 使用真实后端合成课程检查 12 个页面和密码显示切换，涵盖登录选课、教师概览和逐题结果、学生作答、提交历史、B0/D1、学习报告及已提交互评。390px 检查教师作业和学生 D1。截图见本目录。
