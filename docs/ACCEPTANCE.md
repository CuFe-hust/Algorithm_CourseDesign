# 阶段与整体验收

当前main验收的是共享后端最小链路；下表后续场景用于三个Issue联调，不表示当前全部通过。

| 场景 | 主责/配合 | 进入条件 | 可观察交付 |
|---|---|---|---|
| B01 底座启动 | A提供，T/S各自执行 | main及本机PostgreSQL/Python | 空验证库迁移、种子、登录读题提交模拟结果；本机已通过 |
| B02 统一前端 | T00/S/A | B01 | 同一Vue工程登录/课程导航，三个模块挂载，无第二套客户端 |
| B03 名单导入 | T/A | T01 | 预览、错误行、同名、重复学号、班级冲突与重复导入行为清楚，失败不半写 |
| B04 四类作业 | T/S/A | T02/T03、S01 | 教师新建并发布四类题，学生读到固定版本并提交；草稿/越权/截止均校验 |
| B05 匿名互评 | A01/T05/S03 | 新评审表/迁移/DTO | 6份答案每份2名评审，平衡且无自评；学生只看本人匿名任务，评分和评语实际保存 |
| B06 聚合与异常 | A02/T05/S03 | B05 | 四类异常和正常样例、样本不足、教师处置、补评/重算与失败回滚可追踪 |
| B07 发布与统计 | A03/T04/S04 | B06或纯编程结算就绪 | 纯编程/主观/混合三种结算，发布后本人反馈和教师查询同版本，缺交/待评单列 |
| B08 真实评测 | A04，三人协助 | 隔离环境与固定语言 | 正确/错误/超时/运行错误程序有真实判定及资源；编译/系统故障区分，无隐藏测试泄露 |
| B09 算法实验 | A05三人认领 | 业务稳定 | 至少2～3核心问题思想/流程/时空复杂度/基线对比/原始输出/图表/局限可复现 |

每个场景提供操作步骤、样例、预期和实际结果。mock数据持续标记；最终算法与真实执行效果不得用模拟数值替代。T/S/A各交自己章节、代码验证及来源/AI用途说明，汇编不等于代写。

当前自动化测试27项，包含权限、并发、幂等、事务、迁移和模拟输入快照；有一次上游TestClient弃用提醒，尚不影响测试通过。真实其他机器、完整Vue页面和后续场景需要对应成员完成验证。
