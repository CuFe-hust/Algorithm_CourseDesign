# 主观互评与聚合异常的功能范围

对应会议图的第③、④条业务链路。验收基于真实学生任务及原始评价；DEMO 是独立的合成演示。

## 用户流程与验收

| 场景 | 预期行为 |
|---|---|
| 冻结输入 | 作业已关闭且提交截止已到达。固定每位应交学生截止前最后一个未撤回版本、题目、量表、名单和评审人群。未交作品明确保留为空 |
| 分配预览 | 无自评、无禁止关系、每份作品人数满足要求、负载均衡；不可行解释原因，不能发布半份计划 |
| 教师开放 | 显式确认，重新检查冻结范围的摘要；名单或答案变更会要求重新预览 |
| 学生评审 | 仅本人任务可访问；不提供作者身份、参考答案、其他评审结果。首次打开由服务器计时；按量表全部维度评分并填写评语 |
| 原始评价 | 分数越界、缺维度、重复维度、伪造身份或客户端时间均拒绝；提交重试幂等。提交后分项、总分、评语、原时间不可编辑 |
| 封存 | 到期后由教师封存；到期前有未完成任务时须明确接受缺评并说明理由。与学生提交并发也不能遗漏已接受的评分 |
| 初步分析 | 固定评价集，保存候选综合分、分歧与样本数；四类信号分别运行，证据不足与“未发现信号”分开 |
| 复核处置 | 教师确认四类检测的实际状态，填写理由，选择保留、降权、作废或按本题满分改分。信号本身不扣分 |
| 新版本重算 | 保留初步基准与原始分，只追加处置及重算版本；新版本尚未完成时不冒用旧版本为当前有效结果 |
| 补评 | 沿用原作品及量表，仍需预览、确认开放、学生本人评分、封存。排除作者和此前所有已分配者，包括未完成者，避免同一作品重复给同一人 |
| 下游交接 | 输出逐题候选、版本和来源。缺交、缺评、等待处理为明确空值；真实零分仍为零。发布与其他链路由对应负责人接入 |

## 限制与边界

- 单题最多300位应交学生、每轮最多2000个任务、最多9个补评轮次。超界拒绝，不截断真实任务。
- 原始评价数达到最低样本要求才计算候选分；不足时可补评或由教师独立改分并记录理由。
- 关系结构、时长及偏差都是核查线索，不能据此判定作弊。没有足够历史时长期偏差信号明确不足。
- 匿名指移除身份字段与访问隔离；学生自行写在正文中的姓名、学号不自动篡改或识别，教学时应要求匿名作答。
- 不新增作业总分，不替第⑤条链路发布成绩，不替第②、⑥条链路生成内容检测或学习分析结论。
