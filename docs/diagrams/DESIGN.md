# 图形规范：清晰层序

以一致网格表达系统中的稳定关系。整体使用浅色背景、深色标题和明确分区；表、模块和状态各自拥有固定视觉层级，避免把装饰当作信息。密集图仍保留充分留白，主线比辅助字段更醒目。

教师、学生、分析分别使用蓝、绿、琥珀色，同时保留文字标识；当前能力用实线，规划用虚线。精确对齐、清楚的箭头端点和一致间距共同构成可信的工程感，所有连线都应经过逐项校验。

中文标题用于解释业务，英文表名和字段用于查代码。字号按投影阅读设计，严禁为了塞进更多字段无限缩小文字。字段适度选取，完整信息留在数据字典和外键清单中。

成品直接绘制为3840×2160像素，并保存矢量源文件和生成脚本。第二遍检查重点是边界、碰撞、标签含义和状态真实性；精心校准结构与排版，让图成为可共同指认的讨论材料。
