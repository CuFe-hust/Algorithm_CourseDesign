# 第③、④条链路：前端设计

沿用 Vue 3 / TypeScript、现有 session、API、Markdown 安全渲染、确认框和教师/学生布局，不引入第二套登录。

模块：`frontend/src/features/analytics/peer-review/`。

| 页面/文件 | 路由与职责 |
|---|---|
| `TeacherRounds.vue` | `/teacher/reviews`：课程内轮次分页、主观题选择、截止、最低样本、均值/中位数、任务上限、禁止关系、创建理由 |
| `TeacherRound.vue` | `/teacher/reviews/:id`：分配可行性/负载、教师确认、延期/封存、分页原始任务与评语、四类证据确认、处置队列、补评、候选结果、历史只读版本 |
| `StudentTasks.vue` | `/student/courses/:courseId/reviews`：本人任务、状态、截止、分页 |
| `StudentTask.vue` | `/student/courses/:courseId/reviews/:taskId`：匿名作品、冻结量表、逐项分、评语、确认提交、原始评价只读 |
| `types.ts` / `review.css` | 领域 DTO、中文状态、时区转换与响应式布局 |

教师侧菜单为“互评与复核”，学生侧为“我的互评”。教师课程切换沿用现有路由守卫，学生任务还由后端独立验证实际课程及本人身份。

## 交互规则

- 预览不等于发布；仅完整可行的算法结果可点击确认开放。失败分配及分析可显式重试，重试次数由后端约束。
- 四类检测均完成且教师逐项确认状态、填写理由后才允许复核；证据不足不会被显示为正常。原始评价查看不会启动学生计时。
- 每条处置单独填写理由并加入队列；提交后一次事务保存，失败不清空输入。补评仍需进入新轮次确认开放。
- 评分初值为空，不预填0；每维度校验范围和最多两位小数。提交前确认不可修改，失败保留输入和请求ID，已成功评价只读。
- 64位身份/题目/评价/量表ID始终作为字符串传输，避免 JavaScript Number 舍入；Decimal 分数提交为字符串。
- `datetime-local` 在提交时转 UTC，显示使用浏览器本地时区。最终是否到期由服务器判断，客户端不提交计时值。
- 教师计算中每2.5秒刷新已有计算状态；人工等待不自动推进。离开卸载定时器，错误显示请求编号。学生需手动刷新任务。
- 有未提交复核或评分时，路由离开和浏览器关闭均提示。正文沿用带清洗的 Markdown 渲染。
- 候选表对未交、缺评、处理中显示“—”及原因，不把缺失渲染为0；页面明确说明后续成绩发布边界。
