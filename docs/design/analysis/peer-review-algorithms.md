# 主观互评：算法、正确性与限制

实现位置：`backend/app/analysis/algorithms/review.py`、`baseline.py`；契约与独立输出校验位于 `analysis/framework/`。以下为可执行、可替换的确定性基线，不宣称已验证对真实作弊的识别精度。

## ALG-ALLOC：带凸负载成本的最小费用最大流

设作品数 A，候选评审人数 R，每份需求 kᵢ（主轮相同，补评允许不同），总任务数 F=Σkᵢ。构造源点→作品（容量kᵢ）→允许的评审人（容量1）→汇点。作者、自定义禁止关系、当前主轮此前所有任务对应的边均不允许。补评排除已分配但未完成者也是本实现的保守政策。

评审人已有负载 lᵣ 到汇点的第 j 个单位槽费用为 `2(lᵣ+j)+1`，j 从0开始。因此新分配 xᵣ 个任务的增量费用之和恰为 `(lᵣ+xᵣ)²−lᵣ²`，最小化总凸负载；指定总上限时删掉超出上限的槽。

作品→评审人的软成本先惩罚固定历史中的作者/评审人重复次数，再用 SHA256(seed, answer_key, reviewer_key) mod 31 决定确定性平局。取 `H=31F+1`，`W=F(max_history·H+31)+1`，总成本为：槽费用×W＋历史重复×H＋平局值。因此任何整数级凸负载改进都严格优先于全部软成本，任何一次历史重复改进也严格优先于全部平局差。固定排序与种子保证相同输入重放一致，不以随机贪心声称最优。

采用带势能的 Dijkstra 逐次最短增广路。初始正向费用非负、反向边初始容量0，初始势能0合法；每次按可达最短距离更新势能，残量可用边保持非负约化费用。增广允许撤销此前分配，避免局部贪心把后面的作品锁死。

整数容量使结果为整数流；作品到评审人单位容量保证同轮不重复。流量达到 F 时每份作品入流全部满足；若残量网络无增广路，根据最大流性质，不存在满足约束的完整分配。不可行只返回约束原因及空边集，绝不发布部分计划。业务层发布前再独立校验引用、自评、重复、禁止关系、每份人数、上限和负载统计。

令 V=A+R+2，E=O(AR+R·min(A,F))，该实现时间 `O(F·E·log V)`，空间 `O(V+E)`。边界为 A,R≤300、F≤2000。不是大规模竞赛优化器；超界应拆分范围，不能截断样本。穷举小例校验凸负载全局最优；规模实验见 [review-experiments.json](../../../data/analysis/review-experiments.json)，可由 `python -m scripts.review_experiments` 复现，耗时依机器变化。

参考：Boost 官方文档的[逐次最短路最小费用流](https://www.boost.org/doc/libs/1_82_0/libs/graph/doc/successive_shortest_path_nonnegative_weights.html)。本项目为独立 Python 实现，未依赖 Boost。

## ALG-AGG：显式加权聚合

量表满分 B 为冻结维度满分之和；原分 sₑ 必须在[0,B]，归一化为 sₑ/B。原始权重1；教师明确降权设为指定绝对值，作废权重0，KEEP恢复1。只对正权重记录计算有效样本数，不以加权和伪装人数。

- `weighted_mean`：`Σ(wₑsₑ)/(BΣwₑ)`。
- `weighted_median`：按原分、评价键稳定排序，取累积正权重首次达到总权重一半的原分/B，平局取较低端。
- 分歧为有效归一化分数的极差。该字段是描述性极差，不是方差或置信区间。
- 原有聚合输出保留6位小数；本题候选分＝归一化值×本题满分，Decimal ROUND_HALF_UP到两位。
- 样本不足：归一化值和分歧为空，有效人数与原因保留；真实0分仍为有效数值0。
- 教师作品改分在新版本中另记 `TEACHER_OVERRIDE`；保留原聚合值，按本题满分换算归一化，不改原评价分。

实现逐作品扫描评价，时间O(AE)；中位数每组额外排序，总上界O(AE+E log E)，空间O(A+E)。E≤各封存轮次任务总数，补评最多9轮。

## 四类检测：独立证据，不自动处置

| 类型 | 固定规则 | 证据不足条件 |
|---|---|---|
| DEV 单次偏离 | 同作品其他正权重且不同评审人的归一化分数中位数作为 leave-one-out 基准；绝对残差大于阈值（默认0.2）发出评价级信号 | 没有足够其他评审人（默认2）或本范围有无法比较的记录 |
| BIAS 长期偏差 | 同评审人的历史独立基准残差，按不同历史作品取中位数；绝对值大于阈值（默认0.15），区分偏高/偏低 | 当前评审人没有至少3份可比历史作品，或部分人的历史不足 |
| TIME 评审时长 | 只读首次打开→提交的服务器时长。短时阈值为 min(15秒，中位时长×0.2)，严格小于才提示 | 已知时长少于5、存在缺失时长，或中位时长为0而相对基准退化 |
| REL 关系结构 | 把显著正残差表示为“评审人→作者”边，Tarjan SCC查找互相高评/有向环；组内至少2人且证据达到最低数，返回密度与边/评价数 | 没有可比残差或部分记录无独立基准 |

检测初聚合后并行调用独立黑盒，TIME 无需等待初聚合。DEV/REL 不把目标评价纳入自己的参考中位数；BIAS 的历史输入也预先生成排除该评审人的独立基准。固定初步输入与基准在教师处置后不被覆盖，新版本再聚合，无递归反复降权。

DEV 朴素同题筛选上界O(E²)、BIAS 分组及中位数O(H log H)、TIME O(E log E)、REL 的残差部分O(E²)，SCC部分O(V+G)。当前实现重在有界教学场景、可解释性与复现实验；未做真实标签数据上的精度承诺。与异常值标注的一般区分可参考 [NIST 异常值指南](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h.htm)：信号用于调查，不能自动认定数据错误或学生违规。

SCC 高评环既可能来自互相帮助或小样本，也可能只是共同水平较高。时长包含空闲与离开页面，不能代表认真程度；绝对阈值设为0表示不产生短时信号。少量同伴可能使多个评价同时偏离，中位数也不能代替专家评分。无信号且证据不足必须标记不足，教师仍需逐项确认。
