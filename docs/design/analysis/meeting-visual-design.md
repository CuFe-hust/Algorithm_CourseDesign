# 会议图视觉原则：证据层次

使用3840×2160横向画布与统一网格，将因果依赖和职责边界转化为位置关系。主流程横向阅读，相关模块保持等宽，分支采用独立泳道。对齐、间距和连接线经过逐图校验，使投影时能够依靠空间关系讲清结构。

深蓝表示可信输入、版本与输出，青绿表示真实算法计算，橙色表示人工节点、待评和证据局限，灰色表示历史方案或未覆盖内容。颜色承担语义，不以装饰性渐变暗示可信程度。边界和箭头的精确落点优先于额外图标。

标题、结论和字段形成三个字级。中文使用清晰的无衬线字体，英文编号使用独立字体；关键文字在缩至1080p后仍应可读。每张图只回答一个主要问题，长推导留在算法设计文档和讲稿中。

保持内容与证据的诚实对应：章节轴不包装为心理特质，模型参考分不包装为掌握概率，模拟结果不包装为真人结论。把负例纳入与正例相同的视觉层次，认真校验每个数字、图例和缺失状态。
