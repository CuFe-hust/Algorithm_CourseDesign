## 图1：先在六条路线中定位自己

沿用之前的编号：学生端同学负责1—2，教师端同学负责3—4；5号作业总分线已经撤销，我本轮重点完成6号线的章节评价算法与面板。这里按逻辑职责分工，不表示所有领域服务已经完成上线。

第1线的编程结果和第4线的主观题聚合结果，形成可用于第6线的定版单题成绩。第2线的内容/AI信号可以独立产出，先供教师复核，不能直接变成扣分。第3—4线含教师开放、学生评分、人工复核等必须有人参与的步骤。

第6线的输入是前序保存的逐题结果，既不是作业总分，也不要求先生成一个综合rating。当前正式计分和真实互评来源仍需队友接入，演示数据一直标为合成。

## 图2：按左—中—右讲主架构

### 左边：没有这些输入，分数就缺少语义

需要定版的单题归一化成绩，且编程题、分析题、证明题和开放题都可以参与。还需要匿名学生名单、实际布置关系、章节归因权重、教师1—5级难度和相关版本。

名单与布置关系分开，是为了区分“这个学生还没有被布置这一章”和“布置了，但未交或待评”。成绩、映射、评分政策和参数先冻结为输入快照并保存hash；分析过程中不随实时数据库变化。

### 中间：三条逻辑分支，各自回答不同问题

第一条是B0，按章节归因权重计算已评分题的加权均值，回答“这批题上表现怎样”。

第二条是D1。模型把逐题预期分写为 `sigmoid(Σ q·θ − b)`：q说明题目关联哪些章节，θ是学生章节参数，b是题目难度。这里必须指着双向箭头说明：学生参数与题目难度在同一个目标函数中联合迭代；不是先把题目难度算死，再把每个学生当成完全独立对象。

教师1—5级难度只是题目参数的先验位置。实际评分修正它，但校准有正则化约束，避免小样本或极端分数让参数任意发散。我们使用稀疏坐标Newton，每次更新一个参数，回溯检查目标没有增大，更新预测缓存，并通过梯度判断是否收敛。

第三条是过程观察，展示提交次数、首次AC序号和首次/最近/最佳观测分。它补充解释修改过程，但不进入D1损失，不用“提交越少能力越强”来扣分。图中分支是逻辑独立，不宣称当前worker已实际并行执行。

### 右边：保存结果后，再展示给本人

结果包括D1参考分、B0均值、题型子均值、题量、覆盖、缺失、优化状态和实现版本，保存为artifact。学生只能通过本人投影接口读取自己的结果。刷新读取的是保存结果，不会生成新的随机值。

雷达中的D1是参考难度0下的模型期望分，不是掌握概率或经过验证的真实能力。模型内部可以使用先验，页面却不能把没有评分证据的章节补成0.5来画完整形状。

## 图3：雷达轴与数值是什么关系

11个轴来自题库分类文件夹，是课程内容章节，不是“逻辑力、创造力、智力”等心理特质。70道编程题按原目录映射；主观题逐题看题干和评分标准，目前45道暂定映射、5道未归类题不硬塞进雷达。

同一题可以跨章，但总归因权重约为1，权重依据保留以便复核。编程与主观题都可以贡献该章证据，不预设两种题型各占50%。

图中贪心例子来自实际已保存的合成批次：两道编程题35%、46%，一道主观题57%，本章权重都是1，所以B0为46%。联合使用本批其他题和其他学生的评分后，D1模型参考分约为27.3%。它不是从46%扣掉18.7分，也不是学生退步，而是换成了参考难度下的估计对象。

未布置的章节隐藏，已布置但待评或未交的章节留空，低证据显示提示。分治的原始0分仍在B0中保持0，模型参考分可以因正则化而不为0，两者分开标示。

这套图能给出当前证据下的章节表现线索、覆盖不足和补题方向，不能据此认定通用能力、努力程度、是否用AI或岗位胜任力。我们没有把雷达图当成一个证明模型有效的工具；模型有效性另用留出预测检验。

## 图4：讲改进时，对准“问题—机制—证据”

1. 原始均值不考虑题目难度。引入章节参数与题目难度的响应模型，常规合成场景的留出RMSE由B0的0.29530降到D1的0.12703。
2. 教师难度可能标错。将等级作为先验而非真值，再用已有题的评分联合校准。错标场景中，固定先验对照RMSE为0.31256，联合校准D1为0.13039。这里比较的是Fixed与D1，不要误说Fixed也是B0。
3. 连续分、小样本、全0/全1会给估计带来困难。保留连续部分分，使用正则化和数值稳定的稀疏优化；最终对照评估有144次需要优化，全部收敛。192次最终评估还包括不需要拟合的B0，所以不能说192次优化全部收敛。
4. 单独画一个漂亮雷达可能掩盖缺失与口径。保留B0/D1双轨、证据状态、输入hash与本人权限，模型不改写正式题分。

最后主动讲反例：没有真实难度差异时，D1六次重复全部输给B0，RMSE从0.13595变为0.13903；新题难度错标时只胜出4/6次。因此不能宣称复杂模型永远更好，也不能把已有题校准效果外推到未见题。

“创新”应定位为课程场景下的方法适配与工程组合：不是发明了新统计理论，而是把连续评分、章节归因、教师先验、联合校准、稀疏求解和可追溯展示组合为一个可运行、可验证的系统。

## 可能被问到的五个问题

| 问题 | 简短回答 |
|---|---|
| 你究竟测了什么能力？ | 当前是算法课程章节维度的模型参考表现，尚无真人效度证据，不能当通用能力结论。 |
| 为什么只看章节，不分设计、实现、证明能力？ | 当前主要有单题总分。要拆这些能力，需要过程证据或可信rubric分项，不能从一个总分反推。 |
| 模型分比均分低，是扣分吗？ | 不是；一个描述已做题，一个投影到参考难度。正式题分不被改写。 |
| 难度是老师主观标的，靠谱吗？ | 它只是可错的先验，校准并不能保证正确，所以实验专门包含错标和无难度负例。 |
| 与已有平台/论文相比，你做了什么？ | 借鉴分数响应和学生—题目建模，独立完成章节映射、模型/优化器、状态与版本闭环，并做对照/消融与失败场景。 |
