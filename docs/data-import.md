# 数据来源与演示导入

演示数据位于data/demo/problems.json，包含一题编程题及三类主观题。code使用CODE-/SUB-前缀，避免编程P01与证明P01碰撞。JSON是教师侧种子输入，包含参考答案和隐藏用例，禁止直接传给学生前端。

编程题来自已提供Problems/01-贪心算法/P01-活动安排问题.md，题干和Python参考答案整理为便于演示的版本，5组测试按原文件保存。主观题选自已提供Word的A03、P01、O01，手工核对题干/量表；A03保留LaTeX的n>=0和a[i]>=target表达。原Word数学对象不能仅靠提取纯文本自动导入，批量转换后需核对公式。

演示难度映射：编程保留2星，主观基础映射1、中等映射3。CPU1000ms/内存262144KiB为项目演示配置，不声称来自原题限制；它们尚未在真实沙箱使用。

真实名册尚未导入。示例学生使用DEMO2026001～DEMO2026006与合成姓名，两个重名学生用于验证姓名不唯一。账号密码生成到本地.env，仓库不保存实际密码。

教师CSV模板建议student_no,full_name,class_name，UTF-8编码；原xlsx由教师界面或本地转换映射到同一结构。预览校验学号与姓名非空、班级匹配、重复学号、已有学生资料差异；相同文件中重复学号先报错。同学号复用账号但资料更改需教师确认，缺少原有学生不自动删除。确认阶段重新检查并事务写入。当前只提供模板契约，完整CSV导入功能交由教师Issue实现。
